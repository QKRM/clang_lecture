15차시 강의 노트 - Makefile과 라이브러리 아카이브

학습 목표

  1. Makefile의 기본 문법(타겟·의존성·레시피)을 이해한다.
  2. 변수와 패턴 규칙으로 중복을 줄일 수 있다.
  3. ar로 정적 라이브러리(.a)를 만들 수 있다.
  4. libsbs.a를 빌드하고 다른 프로그램에 링크할 수 있다.
  5. all / clean / fclean / re 표준 규칙을 작성할 수 있다.

1부: Makefile이 필요한 이유

지금까지 함수마다 gcc ...를 손으로 쳤습니다. 파일이 23개가 되면 매번 모두 컴파일하는 것은 비효율적입니다. Makefile은 빌드 규칙을 적어두고 make 한 번으로 자동 빌드합니다. 바뀐 파일만 다시 컴파일합니다.

$ make          # 빌드
$ make clean    # 중간 파일 정리

2부: Makefile 기본 문법

2.1 타겟 · 의존성 · 레시피

타겟: 의존성
	레시피     # ← 반드시 탭(Tab)으로 들여쓰기!
  • 타겟: 만들려는 것(파일명 또는 동작 이름)
  • 의존성: 타겟을 만드는 데 필요한 것
  • 레시피: 실행할 명령 (앞에 탭 필수, 스페이스 아님)
hello: hello.c
	cc -Wall -Wextra -Werror hello.c -o hello
레시피 들여쓰기는 반드시 탭입니다. 스페이스면 missing separator 에러.

2.2 변수

반복을 줄입니다.

CC      = cc
CFLAGS  = -Wall -Wextra -Werror
NAME    = libsbs.a

SRCS    = sbs_isalpha.c sbs_toupper.c sbs_strlen.c sbs_strdup.c
OBJS    = $(SRCS:.c=.o)      # .c를 .o로 치환

$(SRCS:.c=.o)는 "SRCS의 모든 .c를 .o로 바꾼 목록"입니다.

2.3 패턴 규칙과 자동 변수

%.o: %.c libsbs.h
	$(CC) $(CFLAGS) -c $< -o $@
  • %.o: %.c — 모든 .o는 같은 이름 .c로 만든다
  • $< — 첫 번째 의존성(여기선 .c)
  • $@ — 타겟 이름(여기선 .o)

3부: ar로 정적 라이브러리 만들기

3.1 정적 라이브러리란?

여러 .o(오브젝트 파일)를 하나의 아카이브 .a로 묶은 것입니다. 다른 프로그램이 이 라이브러리를 링크해 함수를 씁니다.

3.2 ar 명령

$ ar rcs libsbs.a sbs_isalpha.o sbs_toupper.o ...
플래그의미
r아카이브에 추가(있으면 교체)
c아카이브 새로 생성
s인덱스(심볼 테이블) 생성 — 링크 속도

Makefile에서:

$(NAME): $(OBJS)
	$(AR) $(ARFLAGS) $(NAME) $(OBJS)   # ar rcs libsbs.a *.o

3.3 아카이브 확인

$ ar t libsbs.a       # 들어있는 오브젝트 목록
sbs_isalpha.o
sbs_toupper.o
...

4부: 표준 규칙 + 링크

4.1 all / clean / fclean / re

42 계열과 많은 C 프로젝트가 쓰는 관례 규칙입니다.

all: $(NAME)              # 기본 빌드

clean:
	$(RM) $(OBJS)         # .o만 삭제

fclean: clean
	$(RM) $(NAME)         # .o + .a 삭제

re: fclean all           # 전체 재빌드

.PHONY: all clean fclean re   # 동명 파일과 충돌 방지
.PHONY는 "이 타겟은 파일이 아니라 동작"이라고 알려, clean이라는 파일이 있어도 항상 실행되게 합니다.

4.2 라이브러리 링크

# libsbs.a를 링크해 프로그램 빌드
$ cc -Wall -Wextra -Werror main.c -L. -lsbs -o program
  • -L. — 현재 디렉토리에서 라이브러리를 찾음
  • -lsbs — libsbs.a를 링크 (lib와 .a를 뺀 이름)

핵심 정리

  1. Makefile: 타겟·의존성·레시피, 레시피는 탭 들여쓰기
  2. 변수와 $(SRCS:.c=.o)로 중복 제거
  3. 패턴 규칙 %.o: %.c, 자동 변수 $<(소스) $@(타겟)
  4. ar rcs libsbs.a *.o로 정적 라이브러리 생성
  5. all/clean/fclean/re + .PHONY 표준 규칙
  6. -L. -lsbs로 라이브러리 링크

과제 1: 변수 정의

Makefile을 만들고 변수를 정의하세요.

요구사항:

NAME    = libsbs.a
CC      = cc
CFLAGS  = -Wall -Wextra -Werror
AR      = ar
ARFLAGS = rcs
RM      = rm -f

SRCS    = sbs_isalpha.c sbs_toupper.c sbs_strlen.c sbs_strdup.c
OBJS    = $(SRCS:.c=.o)
$(SRCS:.c=.o)는 모든 .c를 .o로 바꾼 목록입니다.

과제 2: 라이브러리 빌드 규칙

요구사항:

  • all 타겟이 $(NAME)을 만든다
  • $(NAME)은 $(OBJS)를 ar로 묶는다
  • 패턴 규칙으로 .c를 .o로 컴파일 (libsbs.h 의존)

힌트:

all: $(NAME)

$(NAME): $(OBJS)
	$(AR) $(ARFLAGS) $(NAME) $(OBJS)

%.o: %.c libsbs.h
	$(CC) $(CFLAGS) -c $< -o $@
레시피 줄은 반드시 탭(Tab)으로 들여쓰기. 스페이스면 missing separator 에러.

과제 3: clean / fclean / re

요구사항:

clean:
	$(RM) $(OBJS)

fclean: clean
	$(RM) $(NAME)

re: fclean all

.PHONY: all clean fclean re
.PHONY로 동명 파일과의 충돌을 막습니다(예: clean이라는 파일이 있어도 동작).

과제 4: 빌드 + 링크 확인

$ make                       # libsbs.a 생성
$ ar t libsbs.a              # 오브젝트 목록 확인
$ make clean                 # .o 삭제
$ make re                    # 전체 재빌드

# 라이브러리 링크 테스트
$ cc -Wall -Wextra -Werror tests/test_link.c -L. -lsbs -o run
$ ./run
LINK_OK
  • -L. 현재 폴더에서 라이브러리 검색
  • -lsbs → libsbs.a 링크 (lib/.a 뺀 이름)

📄 libsbs.h
#ifndef LIBSBS_H
# define LIBSBS_H

# include <stddef.h>

/* 데모용 일부 함수 (실제 과정에서는 9~14차시 전체가 들어감) */
int		sbs_isalpha(int c);
int		sbs_toupper(int c);

char	*sbs_strdup(const char *s);

#endif
📄 Makefile
# ============================================================
# libsbs 정적 라이브러리 Makefile (참고 정답)
# ============================================================

NAME    = libsbs.a

CC      = cc
CFLAGS  = -Wall -Wextra -Werror
AR      = ar
ARFLAGS = rcs
RM      = rm -f

SRCS    = sbs_isalpha.c \
          sbs_toupper.c \
          sbs_strlen.c \
          sbs_strdup.c

OBJS    = $(SRCS:.c=.o)

# 기본 타겟: 라이브러리 생성
all: $(NAME)

# .a 아카이브: 오브젝트들을 ar로 묶음
$(NAME): $(OBJS)
	$(AR) $(ARFLAGS) $(NAME) $(OBJS)

# 패턴 규칙: .c → .o (libsbs.h 의존)
%.o: %.c libsbs.h
	$(CC) $(CFLAGS) -c $< -o $@

# 오브젝트만 삭제
clean:
	$(RM) $(OBJS)

# 오브젝트 + 라이브러리 삭제
fclean: clean
	$(RM) $(NAME)

# 전체 재빌드
re: fclean all

.PHONY: all clean fclean re
📄 sbs_isalpha.c
#include "libsbs.h"

int	sbs_isalpha(int c)
{
	if ((c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z'))
		return (1);
	return (0);
}
📄 sbs_strdup.c
#include "libsbs.h"
#include <stdlib.h>

char	*sbs_strdup(const char *s)
{
	size_t	len;
	size_t	i;
	char	*dup;

	len = sbs_strlen(s);
	dup = (char *)malloc(len + 1);
	if (dup == NULL)
		return (NULL);
	i = 0;
	while (i < len)
	{
		dup[i] = s[i];
		i++;
	}
	dup[len] = '\0';
	return (dup);
}
📄 sbs_strlen.c
#include "libsbs.h"

size_t	sbs_strlen(const char *s)
{
	size_t	len;

	len = 0;
	while (s[len])
		len++;
	return (len);
}
📄 sbs_toupper.c
#include "libsbs.h"

int	sbs_toupper(int c)
{
	if (c >= 'a' && c <= 'z')
		return (c - 32);
	return (c);
}
