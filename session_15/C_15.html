Slide 05 / Variables15차시: Makefile과 라이브러리

변수와 치환

NAME   = libsbs.a
CC     = cc
CFLAGS = -Wall -Wextra -Werror

SRCS   = sbs_isalpha.c \
         sbs_strlen.c ...
OBJS   = $(SRCS:.c=.o)

$(SRCS:.c=.o)

SRCS의 모든 .c를 .o로 바꾼 목록. 반복 제거.

변수 참조는 $(이름). 한 곳만 고치면 전체 반영.

정적 라이브러리

여러 오브젝트(.o)를 하나의 아카이브(.a)로 묶은 것. 다른 프로그램이 링크해 함수를 쓴다.

$ ar t libsbs.a  # 목록 확인

Slide 08 / Rules15차시: Makefile과 라이브러리

표준 규칙 — all / clean / fclean / re

all: $(NAME)

clean:
	$(RM) $(OBJS)

fclean: clean
	$(RM) $(NAME)

re: fclean all

.PHONY: all clean fclean re

all 기본 빌드 · clean .o 삭제

fclean .o+.a 삭제 · re 재빌드

.PHONY

"파일이 아니라 동작". 동명 파일이 있어도 항상 실행.

Standard RulesSession 15
Slide 09 / Link15차시: Makefile과 라이브러리

라이브러리 링크

cc main.c -L. -lsbs -o prog
                  ↑    ↑
              현재폴더  libsbs.a

-L. / -lsbs

-L. 현재 폴더에서 검색. -lsbs = libsbs.a (lib과 .a를 뺀 이름).

링크하면 라이브러리의 sbs_* 함수를 main에서 호출할 수 있다.
