malloc / free 기본 패턴

int *p = malloc(
    sizeof(int) * 10);
if (p == NULL)   // ① 실패 검사
    return (NULL);
/* ... 사용 ... */
free(p);          // ② 반환 (누수 방지)
p = NULL;        // (선택) 댕글링 방지

문자열은 malloc(len + 1) — \0 자리 +1

흔한 실수 3가지

  • • use-after-free (free 후 사용)
  • • double free (두 번 free)
  • • 주소 잃어버려 누수

malloc 성공 = 시작 주소, 실패 = NULL. 검사 없이 쓰면 크래시.

표준 동적 메모리 함수 (<stdlib.h>)

malloc(size)할당 (초기화 X)
calloc(n, size)할당 + 0 초기화
realloc(p, size)크기 재조정
free(p)해제
 
// 0으로 초기화된 배열
int *a = calloc(10, sizeof(int));

// 4 → 8칸으로 확장
int *b = malloc(sizeof(int)*4);
b = realloc(b, sizeof(int)*8);

오늘은 calloc을 직접 만들고, malloc으로 문자열을 만드는 함수들을 구현.

Slide 07 / calloc11차시: 동적 메모리와 malloc

sbs_calloc — 할당 + 0 초기화

total = count * size;
if (count != 0
 && total / count != size)
  return (NULL);  // 오버플로
ptr = malloc(total);
if (ptr == NULL)
  return (NULL);
sbs_memset(ptr, 0, total);
return (ptr);

오버플로 방어

count * size가 넘치면 작은 값이 된다. total / count != size면 NULL.

malloc + 10차시 sbs_memset(0) 재사용.

Slide 08 / substr11차시: 동적 메모리와 malloc

sbs_substr — 부분 문자열을 새 메모리에

slen = sbs_strlen(s);
if (start >= slen)
  len = 0;            // 빈 문자열
else if (len > slen - start)
  len = slen - start; // 끝까지만
sub = malloc(len + 1);
/* s[start+i] 복사 + \0 */
substr("hello world",6,5)
  → "world"
substr("hello",10,5)
  → ""

엣지: start 초과 → "", len 초과 → 남은 길이까지. +1은 \0 자리.

Slide 09 / strjoin11차시: 동적 메모리와 malloc

sbs_strjoin — 문자열 합쳐 새 메모리

l1 = sbs_strlen(s1);
l2 = sbs_strlen(s2);
res = malloc(l1 + l2 + 1);
if (!s1 || !s2 || !res)
  return (NULL);
// s1 복사 후 이어서 s2
// 끝에 \0

malloc 문자열 만들기의 대표

원본 s1·s2는 건드리지 않고 새 메모리에 결과를 만든다.

strjoin("Hello, ","world!")
  → "Hello, world!"

sbs_itoa — 숫자를 문자열로

if (nb < 0)
  { sign=1; nb=-nb; }  // long!
while (tmp >= 10)
  { tmp/=10; len++; }  // 자릿수
str = malloc(len+sign+1);
// 뒤에서부터 채우고
if (sign) str[0] = '-';

INT_MIN 함정

-(-2147483648)은 int 범위 초과. long으로 받아 부호를 뒤집는다(14차시 atoi와 같음).

itoa(-42) → "-42"
itoa(-2147483648)
  → "-2147483648"
