sbs_strlen — 길이 세기

size_t sbs_strlen(const char *s)
{
  size_t len = 0;
  while (s[len])
    len++;
  return (len);
}

7차시 길이 세기

\0까지 세는 로직 그대로. 반환은 size_t, 읽기만 하므로 const.

모든 문자열 함수가 길이를 알아야 하므로 먼저 만들어 재사용한다.

버퍼 오버플로우 — strcpy의 위험

char dst[4];
strcpy(dst, "hello");
// 6바이트를 4바이트에!
// → 다른 메모리 덮어씀

심각한 보안 취약점

strcpy는 dst 크기를 모른다. src가 길면 버퍼를 넘어 인접 메모리를 덮어쓴다.

해법: 크기 인자

strlcpy/strlcat은 dstsize를 받아 절대 넘지 않고 항상 \0 종결.

sbs_strlcpy — 안전 복사

srclen = sbs_strlen(src);
if (dstsize == 0)
  return (srclen);
while (src[i]
    && i < dstsize - 1)
  dst[i] = src[i], i++;
dst[i] = '\0';
return (srclen);

반환값 = src 전체 길이

복사한 수가 아니다. 반환값 >= dstsize면 잘렸다는 신호.

i < dstsize - 1로 마지막 \0 자리 확보. dstsize==0 예외 처리.

sbs_strlcat — 안전 이어붙이기

dstlen = 0;
while (dstlen < dstsize
    && dst[dstlen])
  dstlen++;
if (dstlen == dstsize)
  return (dstsize + srclen);
while (src[i] &&
   dstlen+i < dstsize-1)
  dst[dstlen+i]=src[i], i++;
dst[dstlen+i] = '\0';
return (dstlen + srclen);

까다로운 반환값

dst에 \0이 dstsize 안에 없으면 dstsize + srclen. 정상은 dstlen + srclen.

dst 길이를 dstsize 안에서만 측정해 비정상 버퍼를 방어.

잘림 감지 예시

char buf[4];
size_t n =
  sbs_strlcpy(buf, "hello", 4);

// buf = "hel\0"
// n = 5
if (n >= 4)
  // 잘림 발생!

왜 안전한가

버퍼 4바이트에 3글자+\0만 안전하게 들어가고, 반환값 5로 "원래 5글자였다"를 알려준다. 넘침 없음.
