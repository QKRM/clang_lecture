sbs_split — char ** 를 반환한다

sbs_split("echo hello world", ' ')

 arr ─▶ ┌───────┐
        │  •────┼──▶ "echo\0"
        │  •────┼──▶ "hello\0"
        │  •────┼──▶ "world\0"
        │ NULL  │  ← 끝 표시
        └───────┘

char ** = 2단계

배열 한 개 + 그 안의 문자열 여러 개. 그래서 해제도 2단계.

끝은 NULL로 표시

문자열이 \0로 끝나듯, 포인터 배열은 NULL로 끝난다.

Slide 07 / Strategy16차시: 미니셸

2단계 전략 — 세고, 자른다

1차: 단어 세기

배열을 malloc하려면 단어 개수를 먼저 알아야 한다. count_words로 한 번 훑어 개수 결정.

2차: 잘라 복사

단어마다 sbs_substr(11차시)로 잘라 새 메모리에 복사. 바퀴를 다시 만들지 않는다.

malloc 크기 = sizeof(char *) * (단어 수 + 1)   ← +1은 마지막 NULL 자리

Slide 08 / Code16차시: 미니셸

sbs_split 핵심 코드

char **sbs_split(const char *s, char c)
{
    words = count_words(s, c);
    arr = malloc(sizeof(char *) * (words + 1));   // +1 = NULL 자리
    if (arr == NULL) return (NULL);
    i = 0; k = 0;
    while (k < words) {
        while (s[i] == c) i++;              // 구분자 건너뛰기
        start = i;
        while (s[i] && s[i] != c) i++;      // 단어 끝 찾기
        arr[k] = sbs_substr(s, start, i - start);  // 11차시 재사용!
        k++;
    }
    arr[k] = NULL;                          // 끝 표시
    return (arr);
}

Slide 09 / Free16차시: 미니셸

char ** 해제 — 순서가 생명

 arr ─▶ ┌───────┐
        │  •────┼─▶ "echo"  ① free
        │  •────┼─▶ "hello" ① free
        │  •────┼─▶ "world" ① free
        │ NULL  │
        └───────┘  ② free(arr)

배열을 먼저 free하면?

안에 있던 단어들의 주소를 잃어 영영 해제 못 함 → 메모리 누수.

올바른 순서

안쪽 단어부터, 바깥 배열은 마지막. NULL을 넣어도 안전하게.

Slide 11 / Dispatch16차시: 미니셸

run_command — 이름 보고 갈래 정하기

if (args[0] == NULL)        return (0);   // 빈 줄 먼저! NULL 역참조 방지
if (sbs_strcmp(args[0], "exit") == 0) return (1);  // 종료 신호
if (sbs_strcmp(args[0], "echo") == 0)  builtin_echo(args);
else if (sbs_strcmp(args[0], "upper") == 0) builtin_upper(args);
else if (sbs_strcmp(args[0], "len") == 0)   builtin_len(args);
else if (sbs_strcmp(args[0], "help") == 0)  builtin_help();
else  printf("minishell: %s: command not found\n", args[0]);

함정: args[0]==NULL을 안 보고 strcmp하면 빈 줄에서 크래시 (13차시 NULL 역참조)

Slide 12 / main16차시: 미니셸

메인 루프 — 15차시 껍데기 + 3줄

while (!done) {
    printf("minishell$ "); fflush(stdout);      // 15차시
    if (fgets(line, BUF_SIZE, stdin) == NULL) break;  // Ctrl+D
    strip_newline(line);                          // sbs_strlen
    args = sbs_split(line, ' ');              // + 쪼개기
    if (args == NULL) break;
    done = run_command(args);                     // + 판별·실행
    sbs_free_split(args);                         // + 해제(누수 방지!)
}

뼈대는 15차시 그대로. 늘어난 건 split → run_command → free_split 딱 세 줄.
