차시별 주석 구분

이 헤더 + libsbs.a 두 개만 있으면 다른 프로젝트에서 라이브러리를 쓸 수 있다.

Slide 05 / Makefile16차시: libsbs 종합 프로젝트

통합 Makefile

SRCS = sbs_isalpha.c ... \
       sbs_strdup.c  # 24개
OBJS = $(SRCS:.c=.o)

$(NAME): $(OBJS)
	ar rcs $(NAME) $(OBJS)
%.o: %.c libsbs.h
	$(CC) $(CFLAGS) -c $< -o $@
$ make
$ ar t libsbs.a | wc -l
24

15차시 문법 그대로. SRCS에 24개만 나열하면 make가 전부 빌드.

Slide 07 / Checklist16차시: libsbs 종합 프로젝트

리뷰 체크리스트

정확성

  • □ 엣지 케이스(빈문자/NULL/0)
  • □ 반환값이 명세와 일치
  • □ \0 종결, 버퍼 범위

메모리 안전

  • □ malloc 후 NULL 검사
  • □ free 또는 책임 명시
  • □ 오버플로 방어, const

스타일

  • □ 탭 들여쓰기, 상단 선언
  • □ sbs_ 접두사 snake_case
  • □ 경고 0 (-Werror)

중복/재사용

  • □ 작은 함수 재사용
  • □ isalnum→isalpha+isdigit
  • □ 매직 넘버 줄이기
