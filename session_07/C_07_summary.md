# 7차시: 문자열과 포인터

## 학습 목표

1. C 문자열 구조(char 배열 + `\0`)를 설명할 수 있다
2. char 배열과 char 포인터의 차이를 구분한다
3. 포인터로 문자열을 순회할 수 있다
4. 문자열 리터럴이 읽기 전용임을 안다
5. 문자열 뒤집기/변환을 구현할 수 있다

---

## 핵심 개념

### 1. 문자열 = char 배열 + \0

```c
char s[6] = "hello";
// 'h''e''l''l''o''\0'  ← 6바이트
```

> 글자 5개여도 메모리는 6칸. `\0`이 끝을 알린다. 없으면 폭주.

---

### 2. 배열 vs 포인터

```c
char  arr[] = "hello";   // 복사본, 수정 가능
char *ptr   = "hello";   // 리터럴, 읽기 전용
```

| | `char arr[]` | `char *ptr` |
|-|-------------|-------------|
| 수정 | 가능 | 크래시 |
| 용도 | 내용 변경 | 읽기만 |

> "바꾸면 배열, 읽으면 포인터"

---

### 3. 포인터로 순회

```c
char *p = s;
while (*p)        // \0이면 종료
{
    printf("%c", *p);
    p++;
}
```

> `while (*p)` = "\0이 아닌 동안". 12차시 `sbs_strlen`의 핵심.

---

### 4. 문자는 ASCII 정수

```c
'A'==65  'a'==97  '0'==48  ' '==32

char up = 'a' - 32;   // 'A' (소문자-32=대문자)
char lo = 'Z' + 32;   // 'z'
```

범위 판별:
```c
if (c >= 'a' && c <= 'z')   // 소문자
if (c >= '0' && c <= '9')   // 숫자
```

> 9차시 `sbs_isalpha`, `sbs_toupper`의 토대.

---

### 5. 문자열 뒤집기 (swap 응용)

```c
while (left < right)
{
    char tmp = s[left];
    s[left] = s[right];
    s[right] = tmp;
    left++;
    right--;
}
```

> 양끝→가운데. 배열에만 (리터럴 금지).

## 트러블슈팅

| 증상 | 확인 사항 |
|------|----------|
| 출력에 쓰레기 글자 | `\0` 누락. 배열 크기 = 글자수+1 |
| 문자열 수정 시 크래시 | 리터럴 포인터 수정. `char arr[]` 사용 |
| 길이가 1 큼/작음 | `\0`을 셌거나 마지막 글자 빠뜨림 |
| 대소문자 변환 안 됨 | ±32 방향 확인 (소문자-32=대문자) |
| 뒤집기 결과 이상 | right 시작이 마지막 글자(len-1)인지 확인 |
