# 7차시 강의 노트 - 문자열과 포인터

## 학습 목표

1. C 문자열의 구조(`char` 배열 + null terminator)를 설명할 수 있다.
2. `char` 배열과 `char` 포인터의 차이를 구분할 수 있다.
3. 포인터로 문자열을 한 글자씩 순회할 수 있다.
4. 문자열 리터럴이 읽기 전용임을 이해한다.
5. 문자열을 뒤집고 변환하는 함수를 구현할 수 있다.

---

## 1부: C 문자열의 정체

### 1.1 문자열은 char 배열이다

C에는 `string` 타입이 없습니다. 문자열은 **`char`들의 배열**이고, 끝에 **null terminator(`\0`)** 가 붙습니다.

```c
char s[6] = "hello";
```

```
인덱스   0    1    2    3    4    5
값      'h'  'e'  'l'  'l'  'o'  '\0'
```

`"hello"`는 글자 5개지만 메모리는 **6칸**입니다. 마지막 `\0`이 "여기서 끝"을 알립니다.

### 1.2 \0이 없으면?

`\0`이 없으면 문자열이 어디서 끝나는지 알 수 없어, `printf`나 길이 계산이 메모리를 넘어 폭주합니다. 모든 C 문자열 함수는 `\0`을 기준으로 멈춥니다.

```c
char bad[3] = {'h', 'i', '!'};   // \0 없음 → 문자열로 쓰면 위험
char ok[4]  = {'h', 'i', '!', '\0'};  // 안전
```

> `\0`은 **값이 0**인 한 바이트입니다. 화면에 보이는 **문자 `'0'`(값 48)** 이나 공백(값 32)과는 전혀 다릅니다. `\0`은 "문자열의 끝" 표시일 뿐, 출력되는 글자가 아닙니다.

## 2부: char 배열 vs char 포인터

### 2.1 두 가지 선언

```c
char  arr[] = "hello";    // 배열: 내용을 스택에 복사, 수정 가능
char *ptr   = "hello";    // 포인터: 읽기 전용 리터럴을 가리킴
```

| 구분 | `char arr[]` | `char *ptr` |
|------|--------------|-------------|
| 메모리 | 글자들을 복사해 가짐 | 리터럴 주소만 가리킴 |
| 수정 | `arr[0] = 'H'` 가능 | `ptr[0] = 'H'` **위험**(크래시) |
| 용도 | 내용을 바꿀 때 | 읽기만 할 때 |

### 2.2 리터럴은 읽기 전용

`"hello"` 같은 문자열 리터럴은 읽기 전용 영역에 있습니다. 포인터로 가리켜 수정하려 하면 크래시합니다.

```c
char *ptr = "hello";
ptr[0] = 'H';        // 위험! 읽기 전용 메모리 수정 시도

char arr[] = "hello";
arr[0] = 'H';        // OK — arr은 자기 복사본을 가짐 → "Hello"
```

> "내용을 바꿔야 하면 배열, 읽기만 하면 포인터"로 기억하세요.

## 3부: 포인터로 문자열 순회

### 3.1 \0까지 읽기

문자열 길이를 미리 모르므로 `\0`을 만날 때까지 돕니다. `while (*p)`는 "`*p`가 `\0`(0, 거짓)이 아닌 동안"을 뜻합니다.

```c
char *p = "hello";
while (*p)          // *p가 \0이면 종료
{
    printf("%c", *p);
    p++;            // 다음 글자로
}
// hello
```

### 3.2 길이 직접 세기

```c
int len = 0;
char *p = s;
while (*p)
{
    len++;
    p++;
}
// len = \0 직전까지의 글자 수
```

이것이 12차시 `sbs_strlen`의 핵심 로직입니다. 6차시 포인터 순회(`p++`)가 그대로 쓰입니다.

### 3.3 인덱스 방식과 같다

```c
int i = 0;
while (s[i])        // s[i]가 \0이면 종료
{
    printf("%c", s[i]);
    i++;
}
```

`s[i]`와 `*(s + i)`는 같습니다(6차시). 두 방식 다 익숙해지세요.

## 4부: 문자 다루기

### 4.1 문자는 숫자다 (ASCII)

`char`는 사실 작은 정수입니다. 각 글자는 ASCII 코드값을 가집니다.

```c
'A' == 65    'a' == 97    '0' == 48    ' ' == 32
```

```c
char c = 'A';
printf("%d\n", c);        // 65
printf("%c\n", c + 1);    // B (66)
```

### 4.2 대소문자 변환

`'a'`와 `'A'`는 32 차이입니다. 더하고 빼서 변환합니다.

```c
char lower = 'a';
char upper = lower - 32;   // 'A'  (소문자 - 32 = 대문자)

char up = 'Z';
char low = up + 32;        // 'z'  (대문자 + 32 = 소문자)
```

### 4.3 범위 판별

```c
if (c >= 'a' && c <= 'z')   // 소문자인가?
if (c >= 'A' && c <= 'Z')   // 대문자인가?
if (c >= '0' && c <= '9')   // 숫자 문자인가?
```

> 9차시 `sbs_isalpha`, `sbs_toupper` 등이 이 범위 판별과 ±32 변환을 그대로 구현합니다. 오늘이 그 토대입니다.

## 5부: 문자열 뒤집기 (실습 미리보기)

양 끝에서 가운데로 좁히며 두 글자를 맞바꿉니다(5차시 swap 응용).

```c
void reverse(char *s)
{
    int left = 0;
    int right = 0;
    while (s[right])        // 길이 끝(\0 직전) 찾기
        right++;
    right--;                // 마지막 글자 인덱스
    while (left < right)
    {
        char tmp = s[left];
        s[left] = s[right];
        s[right] = tmp;
        left++;
        right--;
    }
}
```

배열(`char arr[]`)에만 써야 합니다. 리터럴 포인터에 쓰면 크래시합니다.

---

## 핵심 정리

1. C 문자열 = `char` 배열 + 끝의 `\0`(null terminator)
2. `"hello"`는 6바이트 (글자 5 + `\0` 1)
3. `char arr[]`는 수정 가능, `char *ptr = "..."`는 읽기 전용
4. `while (*p)`로 `\0`까지 순회 (길이를 몰라도 됨)
5. 문자는 ASCII 정수 — 대소문자는 ±32로 변환
6. 문자열 뒤집기는 양끝→가운데 swap (배열에만)
