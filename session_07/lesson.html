문자열과 포인터

📝 수업 마무리 퀴즈 (15문항) 퀴즈 풀기 내려받기

학습 목표

  1. C 문자열의 구조(char 배열 + null terminator)를 설명할 수 있다.
  2. char 배열과 char 포인터의 차이를 구분할 수 있다.
  3. 포인터로 문자열을 한 글자씩 순회할 수 있다.
  4. 문자열 리터럴이 읽기 전용임을 이해한다.
  5. 문자열을 뒤집고 변환하는 함수를 구현할 수 있다.

1부: C 문자열의 정체

1.1 문자열은 char 배열이다

C에는 string 타입이 없습니다. 문자열은 char들의 배열이고, 끝에 null terminator(\0) 가 붙습니다.

char s[6] = "hello";
인덱스   0    1    2    3    4    5
값      'h'  'e'  'l'  'l'  'o'  '\0'

"hello"는 글자 5개지만 메모리는 6칸입니다. 마지막 \0이 "여기서 끝"을 알립니다.

1.2 \0이 없으면?

\0이 없으면 문자열이 어디서 끝나는지 알 수 없어, printf나 길이 계산이 메모리를 넘어 폭주합니다. 모든 C 문자열 함수는 \0을 기준으로 멈춥니다.

char bad[3] = {'h', 'i', '!'};   // \0 없음 → 문자열로 쓰면 위험
char ok[4]  = {'h', 'i', '!', '\0'};  // 안전
\0은 값이 0인 한 바이트입니다. 화면에 보이는 문자 '0'(값 48) 이나 공백(값 32)과는 전혀 다릅니다. \0은 "문자열의 끝" 표시일 뿐, 출력되는 글자가 아닙니다.

2부: char 배열 vs char 포인터

2.1 두 가지 선언

char  arr[] = "hello";    // 배열: 내용을 스택에 복사, 수정 가능
char *ptr   = "hello";    // 포인터: 읽기 전용 리터럴을 가리킴
구분char arr[]char *ptr
메모리글자들을 복사해 가짐리터럴 주소만 가리킴
수정arr[0] = 'H' 가능ptr[0] = 'H' 위험(크래시)
용도내용을 바꿀 때읽기만 할 때

2.2 리터럴은 읽기 전용

"hello" 같은 문자열 리터럴은 읽기 전용 영역에 있습니다. 포인터로 가리켜 수정하려 하면 크래시합니다.

char *ptr = "hello";
ptr[0] = 'H';        // 위험! 읽기 전용 메모리 수정 시도

char arr[] = "hello";
arr[0] = 'H';        // OK — arr은 자기 복사본을 가짐 → "Hello"
"내용을 바꿔야 하면 배열, 읽기만 하면 포인터"로 기억하세요.

3부: 포인터로 문자열 순회

3.1 \0까지 읽기

문자열 길이를 미리 모르므로 \0을 만날 때까지 돕니다. while (*p)는 "*p가 \0(0, 거짓)이 아닌 동안"을 뜻합니다.

char *p = "hello";
while (*p)          // *p가 \0이면 종료
{
    printf("%c", *p);
    p++;            // 다음 글자로
}
// hello

3.2 길이 직접 세기

int len = 0;
char *p = s;
while (*p)
{
    len++;
    p++;
}
// len = \0 직전까지의 글자 수

이것이 12차시 sbs_strlen의 핵심 로직입니다. 6차시 포인터 순회(p++)가 그대로 쓰입니다.

3.3 인덱스 방식과 같다

int i = 0;
while (s[i])        // s[i]가 \0이면 종료
{
    printf("%c", s[i]);
    i++;
}

s[i]와 *(s + i)는 같습니다(6차시). 두 방식 다 익숙해지세요.

4부: 문자 다루기

4.1 문자는 숫자다 (ASCII)

char는 사실 작은 정수입니다. 각 글자는 ASCII 코드값을 가집니다.

'A' == 65    'a' == 97    '0' == 48    ' ' == 32
char c = 'A';
printf("%d\n", c);        // 65
printf("%c\n", c + 1);    // B (66)

4.2 대소문자 변환

'a'와 'A'는 32 차이입니다. 더하고 빼서 변환합니다.

char lower = 'a';
char upper = lower - 32;   // 'A'  (소문자 - 32 = 대문자)

char up = 'Z';
char low = up + 32;        // 'z'  (대문자 + 32 = 소문자)

4.3 범위 판별

if (c >= 'a' && c <= 'z')   // 소문자인가?
if (c >= 'A' && c <= 'Z')   // 대문자인가?
if (c >= '0' && c <= '9')   // 숫자 문자인가?
9차시 sbs_isalpha, sbs_toupper 등이 이 범위 판별과 ±32 변환을 그대로 구현합니다. 오늘이 그 토대입니다.

5부: 문자열 뒤집기 (실습 미리보기)

양 끝에서 가운데로 좁히며 두 글자를 맞바꿉니다(5차시 swap 응용).

void reverse(char *s)
{
    int left = 0;
    int right = 0;
    while (s[right])        // 길이 끝(\0 직전) 찾기
        right++;
    right--;                // 마지막 글자 인덱스
    while (left < right)
    {
        char tmp = s[left];
        s[left] = s[right];
        s[right] = tmp;
        left++;
        right--;
    }
}

배열(char arr[])에만 써야 합니다. 리터럴 포인터에 쓰면 크래시합니다.

핵심 정리

  1. C 문자열 = char 배열 + 끝의 \0(null terminator)
  2. "hello"는 6바이트 (글자 5 + \0 1)
  3. char arr[]는 수정 가능, char *ptr = "..."는 읽기 전용
  4. while (*p)로 \0까지 순회 (길이를 몰라도 됨)
  5. 문자는 ASCII 정수 — 대소문자는 ±32로 변환
  6. 문자열 뒤집기는 양끝→가운데 swap (배열에만)

다음 차시 예고

8차시에서는 구조체(struct)와 typedef를 학습합니다. 서로 다른 타입의 데이터를 하나로 묶는 구조체, 타입에 별칭을 다는 typedef, 그리고 구조체 포인터(->)를 다룹니다. 학생 정보 관리 프로그램을 구조체 배열로 만듭니다.

과제 1: 문자열 길이

str_length.c 파일을 만들고 문자열 길이를 직접 세는 함수를 작성하세요. (strlen 사용 금지)

요구사항:

  • int str_length(char *s) — \0까지 글자 수를 셈
  • main에서 여러 문자열로 테스트

출력 예시:

"hello" → 5
"" → 0
"42 seoul" → 8

힌트:

int str_length(char *s)
{
    int len = 0;
    while (s[len])
        len++;
    return (len);
}
12차시 sbs_strlen의 원형입니다. while (s[i])로 \0까지 셉니다.

과제 2: 문자열 출력 (포인터 순회)

str_print.c 파일을 만들고 포인터를 직접 이동시키며 한 글자씩 출력하세요. (printf("%s") 금지, %c만)

요구사항:

  • void str_print(char *s) — *p로 한 글자씩, p++로 이동
  • 끝에 줄바꿈

힌트:

void str_print(char *s)
{
    char *p = s;
    while (*p)
    {
        printf("%c", *p);
        p++;
    }
    printf("\n");
}

과제 3: 대문자 변환

to_upper.c 파일을 만들고 문자열의 소문자를 모두 대문자로 바꾸세요.

요구사항:

  • void to_upper(char *s) — 소문자만 -32, 나머지는 그대로
  • 원본 배열을 직접 수정 (배열로 선언할 것)

출력 예시:

"Hello, 42!" → "HELLO, 42!"

힌트:

void to_upper(char *s)
{
    int i = 0;
    while (s[i])
    {
        if (s[i] >= 'a' && s[i] <= 'z')
            s[i] = s[i] - 32;
        i++;
    }
}
char *s = "..."가 아니라 char s[] = "..."로 만드세요. 리터럴은 수정 불가.

과제 4: 문자열 복사

str_copy.c 파일을 만들고 한 문자열을 다른 배열로 복사하세요. (strcpy 금지)

요구사항:

  • void str_copy(char *dst, char *src) — src를 dst로 \0까지 복사
  • \0도 복사할 것
  • main에서 충분히 큰 dst 배열 준비

출력 예시:

복사 결과: hello world

힌트:

void str_copy(char *dst, char *src)
{
    int i = 0;
    while (src[i])
    {
        dst[i] = src[i];
        i++;
    }
    dst[i] = '\0';   // 끝 표시 잊지 말 것
}
\0을 복사하지 않으면 쓰레기가 붙습니다. 12차시 sbs_strlcpy의 기초.

과제 5: 문자 개수 세기

count_char.c 파일을 만들고 문자열에서 특정 문자가 몇 번 나오는지 세세요.

요구사항:

  • int count_char(char *s, char target) — target과 같은 글자 수 반환
  • 여러 문자로 테스트

출력 예시:

"banana"에서 'a' → 3
"banana"에서 'n' → 2
"banana"에서 'z' → 0

힌트:

int count_char(char *s, char target)
{
    int count = 0;
    int i = 0;
    while (s[i])
    {
        if (s[i] == target)
            count++;
        i++;
    }
    return (count);
}

과제 6: 문자열 뒤집기

str_reverse.c 파일을 만들고 문자열을 제자리에서 뒤집으세요.

요구사항:

  • void str_reverse(char *s) — 양끝에서 가운데로 swap
  • 추가 배열 없이 제자리(in-place) 뒤집기
  • 배열로 선언

출력 예시:

"hello" → "olleh"
"42seoul" → "luoes24"

힌트:

void str_reverse(char *s)
{
    int left = 0;
    int right = 0;
    while (s[right])
        right++;
    right--;
    while (left < right)
    {
        char tmp = s[left];
        s[left] = s[right];
        s[right] = tmp;
        left++;
        right--;
    }
}
5차시 swap을 문자열에 응용. right는 마지막 글자 인덱스(len-1)에서 시작.

과제 7: 모음 개수 세기 (심화, 20분)

count_vowels.c 파일을 만들고 문자열의 모음(a,e,i,o,u 대소문자 모두)을 세세요.

요구사항:

  • int count_vowels(char *s) — 모음 개수 반환
  • 대문자·소문자 모음 모두 인정
  • 보조 함수 int is_vowel(char c)를 만들어 사용

출력 예시:

"Hello World" → 3
"AEIOU" → 5
"xyz" → 0

힌트:

int is_vowel(char c)
{
    if (c >= 'A' && c <= 'Z')
        c = c + 32;   // 소문자로 통일
    return (c == 'a' || c == 'e' || c == 'i'
        || c == 'o' || c == 'u');
}
대소문자를 통일한 뒤 비교하면 조건이 간단해집니다.

과제 8: 회문 판별 (심화, 25분)

palindrome.c 파일을 만들고 문자열이 회문(앞뒤로 같음)인지 판별하세요.

요구사항:

  • int is_palindrome(char *s) — 회문이면 1, 아니면 0
  • 양끝에서 좁혀가며 비교 (뒤집지 말고 직접 비교)
  • 여러 문자열로 테스트

출력 예시:

"level" → 회문
"hello" → 회문 아님
"42024" → 회문

힌트:

int is_palindrome(char *s)
{
    int left = 0;
    int right = 0;
    while (s[right])
        right++;
    right--;
    while (left < right)
    {
        if (s[left] != s[right])
            return (0);
        left++;
        right--;
    }
    return (1);
}

생각해보기: 뒤집어서 비교하는 방법도 있지만, 양끝 비교가 왜 더 효율적일까? (절반만 비교하면 됨)

int	count_vowels(char *s)
{

	i = 0;
	while (s[i])
	{
		if (is_vowel(s[i]))
			count++;
		i++;
	}
	return (count);
}

#include <stdio.h>

int	is_palindrome(char *s);

int	main(void)
{
	char	a[] = "level";
	char	b[] = "hello";
	char	c[] = "42024";

	printf("\"level\" → %s\n", is_palindrome(a) ? "회문" : "회문 아님");
	printf("\"hello\" → %s\n", is_palindrome(b) ? "회문" : "회문 아님");
	printf("\"42024\" → %s\n", is_palindrome(c) ? "회문" : "회문 아님");
	return (0);
}

int	is_palindrome(char *s)
{
	int	left;
	int	right;

	left = 0;
	right = 0;
	while (s[right])
		right++;
	right--;
	while (left < right)
	{
		if (s[left] != s[right])
			return (0);
		left++;
		right--;
	}
	return (1);
}

void	str_reverse(char *s)
{
	int		left;
	int		right;
	char	tmp;

	left = 0;
	right = 0;
	while (s[right])
		right++;
	right--;
	while (left < right)
	{
		tmp = s[left];
		s[left] = s[right];
		s[right] = tmp;
		left++;
		right--;
	}
}

{
	int	i;

	i = 0;
	while (s[i])
	{
		if (s[i] >= 'a' && s[i] <= 'z')
			s[i] = s[i] - 32;
		i++;
