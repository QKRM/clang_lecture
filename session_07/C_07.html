C 문자열의 정체 — char 배열 + \0

string 타입은 없다

문자열 = char들의 배열 + 끝의 `\0`

"hello"는 글자 5개지만 메모리는 6칸.

\0이 없으면?

끝을 몰라 출력·길이 계산이 메모리를 넘어 폭주. 모든 문자열 함수가 `\0`에서 멈춘다.

char s[6] = "hello";

인덱스  0   1   2   3   4   5
값     'h' 'e' 'l' 'l' 'o' \0
                        ↑ 끝 표시

\0은 값이 0인 한 바이트. 숫자 '0'(48)이나 공백과 다르다.

Slide 07 / Reverse 7차시: 문자열과 포인터

문자열 뒤집기 — 양끝→가운데 swap

void reverse(char *s)
{
  int left = 0, right = 0;
  while (s[right]) right++;
  right--;  // 마지막 글자
  while (left < right)
  {
    char t = s[left];
    s[left] = s[right];
    s[right] = t;
    left++; right--;
  }
}

o e l l h  교환
  ↑   ↑
o l l e h  완료

void to_upper(char *s)
{
  int i = 0;
  while (s[i])
  {
    if (s[i]>='a' && s[i]<='z')
      s[i] = s[i] - 32;
    i++;
  }
}

"Hello,42!"→"HELLO,42!"

④ str_copy.c 
void str_copy(char *dst,
              char *src)
{
  int i = 0;
  while (src[i])
  {
    dst[i] = src[i];
    i++;
  }
  dst[i] = '\0';  // 필수!
}

    i++;

{

    c = c + 32;  // 통일
