sbs_strchr — 순방향 검색

while (s[i])
{
  if (s[i] == (char)c)
    return ((char*)(s+i));
  i++;
}
if ((char)c == '\0')
  return ((char*)(s+i));
return (NULL);

\0도 검색 대상

strchr(s, '\0')은 문자열 끝의 \0 위치를 반환(표준). 루프 후 분기 필수.

첫 등장 위치 반환. 못 찾으면 NULL. (char *) 캐스팅.

sbs_strrchr — 역방향 검색

while (s[i]) i++;  // 끝으로
if ((char)c == '\0')
  return ((char*)(s+i));
while (i > 0)      // 뒤→앞
{
  i--;
  if (s[i] == (char)c)
    return ((char*)(s+i));
}
return (NULL);
함수결과
strchr첫 등장
strrchr마지막 등장

먼저 \0까지 이동해 끝 인덱스를 잡고, 뒤에서부터 내려오며 첫 일치 = 마지막 등장.

sbs_strnstr — 부분 문자열 검색

if (little[0] == '\0')
  return ((char*)big);
while (big[i] && i < len)
{
  j = 0;
  while (big[i+j] &&
    i+j < len &&
    big[i+j]==little[j]) j++;
  if (little[j]=='\0')
    return ((char*)(big+i));
  i++;
}
return (NULL);

빈 little

needle이 빈 문자열이면 즉시 big 반환(표준 동작).

이중 루프

바깥 i(시작위치), 안쪽 j(일치 검사). i+j < len으로 범위 제한.

Slide 07 / Matching13차시: 문자열 함수 II

부분 문자열 매칭 추적

big="ababc", little="abc" 
i=0: ab... ab 일치, c≠a → 실패
i=1: b≠a → 실패
i=2: abc 전부 일치 → 발견!
return big+2

시작 위치를 한 칸씩

바깥 루프가 시작 위치 i를 옮기고, 안쪽 루프가 그 자리부터 little과 끝까지 맞는지 본다. little이 \0에 닿으면 전부 일치.

strchr vs memchr — 어디서 멈추나

함수종료 기준입력 타입
strchr (13차시)\0까지const char *
memchr (11차시)n바이트const void *

strchr는 문자열용(\0 기준), memchr는 메모리용(길이 기준). strnstr은 strstr에 길이 제한을 더한 것.
