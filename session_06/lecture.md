# 6차시 강의 노트 - 배열과 포인터

## 학습 목표

1. 배열의 메모리 배치를 설명할 수 있다.
2. 배열 이름이 첫 원소의 주소임을 이해한다.
3. 포인터 산술 연산(`p + 1`, `p++`)을 배열 순회에 활용할 수 있다.
4. 배열을 함수에 전달하는 방법을 이해한다.
5. 버블 정렬을 배열과 포인터로 구현할 수 있다.

---

## 1부: 배열의 메모리 배치

### 1.1 배열은 연속된 공간

배열은 같은 타입의 값을 **메모리에 연속으로** 늘어놓습니다.

```c
int arr[5] = {10, 20, 30, 40, 50};
```

```
주소        값
0x1000     10   ← arr[0]
0x1004     20   ← arr[1]
0x1008     30   ← arr[2]
0x100c     40   ← arr[3]
0x1010     50   ← arr[4]
```

`int`가 4바이트라서 주소가 4씩 늘어납니다. 원소들이 빈틈없이 붙어 있는 게 핵심입니다.

### 1.2 인덱스로 접근

```c
printf("%d\n", arr[0]);   // 10
printf("%d\n", arr[2]);   // 30
```

인덱스는 0부터 시작합니다. `arr[5]`는 범위를 벗어남(out of bounds) — 위험합니다.

---

## 2부: 배열 이름은 곧 주소

### 2.1 배열 이름 = 첫 원소의 주소

배열 이름을 그냥 쓰면 **첫 원소의 주소**(`&arr[0]`)로 변환됩니다.

```c
int arr[5] = {10, 20, 30, 40, 50};

printf("%p\n", (void *)arr);       // 첫 원소 주소
printf("%p\n", (void *)&arr[0]);   // 같은 주소!
```

`arr == &arr[0]`. 이것이 배열과 포인터가 연결되는 지점입니다.

### 2.2 포인터에 배열을 담는다

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;     // &arr[0]과 같음 (& 안 붙임!)

printf("%d\n", *p);       // 1 (첫 원소)
printf("%d\n", arr[0]);   // 1 (같은 것)
```

> 배열 이름은 이미 주소라서 `&`를 붙이지 않습니다. `int *p = arr;`이 맞고 `int *p = &arr;`는 타입이 다릅니다.

---

## 3부: 포인터 산술

### 3.1 `p + 1`은 다음 원소

포인터에 1을 더하면 **타입 크기만큼** 주소가 이동합니다. `int *`면 4바이트 다음, 즉 다음 원소입니다.

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;

printf("%d\n", *p);         // 1
printf("%d\n", *(p + 1));   // 2
printf("%d\n", *(p + 2));   // 3
```

| 표현 | 같은 표현 | 값 |
|------|-----------|----|
| `*(p + 0)` | `arr[0]` | 1 |
| `*(p + 1)` | `arr[1]` | 2 |
| `*(p + i)` | `arr[i]` | arr[i] |

실은 `arr[i]`가 컴파일러 내부에서 `*(arr + i)`로 처리됩니다. 인덱스 문법은 포인터 산술의 줄임말입니다.

### 3.2 포인터를 직접 이동시키며 순회

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;

while (p < arr + 5)   // 마지막 원소 다음까지
{
    printf("%d ", *p);
    p++;              // 다음 원소로 이동
}
// 1 2 3 4 5
```

`arr + 5`는 마지막 원소 **다음** 주소입니다. 순회 종료 기준으로 자주 씁니다.

> libsbs의 문자열 함수는 대부분 이렇게 포인터를 한 칸씩 옮기며 `\0`까지 읽습니다 (7차시).

## 4부: 배열을 함수에 전달

### 4.1 배열은 주소로 전달된다

배열을 함수에 넘기면 **첫 원소의 주소**가 전달됩니다 (복사 아님!). 그래서 함수 안에서 배열을 바꾸면 원본이 바뀝니다.

```c
void fill_zero(int *arr, int size)
{
    for (int i = 0; i < size; i++)
        arr[i] = 0;     // 원본이 바뀐다
}
```

> 4차시의 값 전달(복사)과 다릅니다. 배열은 주소가 넘어가므로 swap처럼 원본을 직접 고칠 수 있습니다.

### 4.2 크기는 따로 넘겨야 한다

함수 안에서는 배열의 크기를 알 수 없습니다(주소만 받았으므로). 그래서 `size`를 항상 같이 넘깁니다.

```c
void print_array(int *arr, int size)   // size 필수
{
    for (int i = 0; i < size; i++)
        printf("%d ", arr[i]);
}
```

`int arr[]`와 `int *arr`는 매개변수에서 같은 뜻입니다.

## 5부: 버블 정렬 (실습 미리보기)

옆 원소와 비교해 큰 값을 뒤로 보내는 과정을 반복합니다.

```c
void bubble_sort(int *arr, int size)
{
    for (int i = 0; i < size - 1; i++)
        for (int j = 0; j < size - 1 - i; j++)
            if (arr[j] > arr[j + 1])
            {
                int tmp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = tmp;
            }
}
```

한 바퀴(바깥 i) 돌 때마다 가장 큰 값이 맨 뒤에 "거품처럼" 떠오릅니다. 그래서 안쪽 범위가 `size - 1 - i`로 줄어듭니다.

---

## 핵심 정리

1. 배열은 같은 타입을 **메모리에 연속**으로 배치
2. 배열 이름 = **첫 원소의 주소** (`arr == &arr[0]`)
3. `int *p = arr;` — 배열 이름엔 `&`를 안 붙인다
4. `*(p + i) == arr[i]`, `p + 1`은 다음 원소
5. 배열을 함수에 넘기면 **주소가 전달**되어 원본이 바뀐다
6. 함수엔 배열 크기(`size`)를 항상 같이 넘긴다
