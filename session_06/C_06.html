배열의 메모리 배치

연속된 공간

같은 타입 값을 메모리에 빈틈없이 늘어놓는다

int가 4바이트라 주소가 4씩 증가.

인덱스는 0부터

arr[0]이 첫 원소. arr[5]는 범위 초과(위험).

int arr[5] = {10,20,30,40,50};

주소        값
0x1000     10   ← arr[0]
0x1004     20   ← arr[1]
0x1008     30   ← arr[2]
0x100c     40   ← arr[3]
0x1010     50   ← arr[4]

배열과 포인터가 연결되는 지점.

&를 붙이지 마라

배열 이름은 이미 주소. int *p = arr;가 맞다. &arr는 타입이 다르다.

Slide 05 / Pointer Arithmetic 6차시: 배열과 포인터

포인터 산술 — p + 1은 다음 원소

int arr[5] = {1,2,3,4,5};
int *p = arr;

printf("%d\n", *p);        // 1
printf("%d\n", *(p + 1));  // 2
printf("%d\n", *(p + 2));  // 3

p + 1 = 타입 크기(4바이트)만큼 이동 = 다음 원소

포인터 산술 인덱스
*(p + 0)arr[0]
*(p + 1)arr[1]
*(p + i)arr[i]

arr[i]는 사실 *(arr + i)의 줄임말. 인덱스 문법 = 포인터 산술.

Slide 07 / Passing Arrays 6차시: 배열과 포인터

배열을 함수에 전달 — 주소가 넘어간다

void fill_zero(int *arr, int size)
{
    for (int i = 0; i < size; i++)
        arr[i] = 0;  // 원본이 바뀐다!
}

4차시 값 전달(복사)과 다르다. 배열은 주소가 넘어가므로 원본을 직접 고친다.

크기는 따로 넘겨라

함수 안에서는 배열 크기를 알 수 없다(주소만 받음). size를 항상 같이 넘긴다.

같은 의미

int arr[]와 int *arr는 매개변수에서 같은 뜻.

Slide 08 / Bubble Sort 6차시: 배열과 포인터

버블 정렬 — 큰 값을 뒤로

void bubble_sort(int *arr, int size)
{
  for (i = 0; i < size-1; i++)
   for (j = 0; j < size-1-i; j++)
    if (arr[j] > arr[j+1])
    {
      tmp = arr[j];
      arr[j] = arr[j+1];
      arr[j+1] = tmp;
    }
}

동작 원리

옆 원소와 비교해 큰 값을 뒤로 민다. 한 바퀴마다 최댓값이 맨 뒤로 "거품처럼" 떠오른다.

범위가 줄어드는 이유

맨 뒤는 이미 정렬됨 → 안쪽 범위 size - 1 - i
