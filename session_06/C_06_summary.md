# 6차시: 배열과 포인터

## 학습 목표

1. 배열의 메모리 배치를 설명할 수 있다
2. 배열 이름 = 첫 원소의 주소를 이해한다
3. 포인터 산술로 배열을 순회할 수 있다
4. 배열을 함수에 전달할 수 있다
5. 버블 정렬을 구현할 수 있다

---

## 핵심 개념

### 1. 배열은 연속된 메모리

```c
int arr[5] = {10, 20, 30, 40, 50};
```

```
0x1000  10  arr[0]
0x1004  20  arr[1]   ← int 4바이트씩 증가
0x1008  30  arr[2]
```

---

### 2. 배열 이름 = 첫 원소 주소

```c
arr == &arr[0]    // 참

int *p = arr;     // & 안 붙임!
printf("%d\n", *p);   // 첫 원소
```

> `int *p = &arr;`는 타입이 다르다. 배열 이름은 이미 주소.

---

### 3. 포인터 산술

`p + 1`은 타입 크기만큼 이동 = 다음 원소.

```c
int *p = arr;
*(p + 0)   // arr[0]
*(p + 1)   // arr[1]
*(p + i)   // arr[i]
```

> `arr[i]`는 내부적으로 `*(arr + i)`. 인덱스는 포인터 산술의 줄임말.

```c
/* 포인터 직접 이동 */
p = arr;
while (p < arr + 5)
{
    printf("%d ", *p);
    p++;
}
```

---

### 4. 배열을 함수에 전달

배열을 넘기면 **주소가 전달**(복사 아님) → 원본이 바뀐다.

```c
void fill_zero(int *arr, int size)
{
    for (int i = 0; i < size; i++)
        arr[i] = 0;   // 원본 변경
}
```

> `int arr[]`와 `int *arr`는 매개변수에서 같다. 크기(`size`)는 항상 따로 넘긴다.

---

### 5. 버블 정렬

```c
void bubble_sort(int *arr, int size)
{
    for (int i = 0; i < size - 1; i++)
        for (int j = 0; j < size - 1 - i; j++)
            if (arr[j] > arr[j + 1])
            {
                int tmp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = tmp;
            }
}
```

한 바퀴마다 최댓값이 맨 뒤로 떠오른다 → 안쪽 범위 `size - 1 - i`.

## 트러블슈팅

| 증상 | 확인 사항 |
|------|----------|
| 정렬이 안 됨 | 안쪽 비교가 `arr[j] > arr[j+1]`인지, 범위 `size-1-i`인지 |
| 이상한 값/크래시 | 배열 범위 초과 (arr[size] 접근 금지) |
| `int *p = &arr` 경고 | 배열 이름엔 `&` 빼기 → `int *p = arr;` |
| 함수에서 크기를 모름 | size를 매개변수로 같이 넘김 |
| 합계가 틀림 | sum 초기값 0, 인덱스 0~size-1 확인 |
