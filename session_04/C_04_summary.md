# 4차시: 함수와 재귀

## 학습 목표

1. 함수를 선언(프로토타입)·정의·호출할 수 있다
2. 매개변수와 반환값을 설명할 수 있다
3. 값에 의한 전달(pass by value)을 이해한다
4. 스택 프레임으로 함수 호출을 설명할 수 있다
5. 재귀를 구현할 수 있다 (종료 조건 + 재귀 호출)

---

## 핵심 개념

### 1. 함수 구조

```c
//  반환타입  이름(매개변수)
int add(int a, int b)
{
    return (a + b);
}
```

| 요소 | 설명 |
|------|------|
| 반환 타입 | 돌려주는 값의 타입 (없으면 `void`) |
| 이름 | 호출 시 사용 (snake_case) |
| 매개변수 | 입력 (없으면 `void`) |
| `return` | 결과 반환 + 함수 종료 |

---

### 2. 선언·정의·호출

```c
int add(int a, int b);   /* 1. 선언(프로토타입) — main 위 */

int main(void)
{
    int r = add(3, 5);   /* 3. 호출 */
    return (0);
}

int add(int a, int b)    /* 2. 정의 — main 아래 */
{
    return (a + b);
}
```

> `main` 아래 정의된 함수를 호출하려면 **프로토타입**을 미리 선언해야 한다. 안 하면 경고/에러.

---

### 3. 값에 의한 전달

인자는 **복사**되어 넘어간다. 함수 안에서 바꿔도 원본은 그대로.

```c
void try_change(int x) { x = 999; }   /* 복사본만 변경 */

int main(void)
{
    int a = 5;
    try_change(a);
    printf("%d\n", a);   /* 5 — 안 바뀜! */
}
```

> 원본을 바꾸려면 **주소(포인터)**를 넘겨야 한다 → 5차시 주제.

---

### 4. 스택 프레임

함수 호출마다 스택에 프레임이 쌓이고, `return` 시 제거된다.

```
main()  → [main]
add()   → [main][add]
add 반환 → [main]
```

지역 변수는 그 함수가 사는 동안만 존재. 함수가 끝나면 사라진다.

---

### 5. 재귀

두 가지가 **반드시** 필요:

```c
int factorial(int n)
{
    if (n <= 1)                     /* 종료 조건 (base case) */
        return (1);
    return (n * factorial(n - 1));  /* 재귀 호출 */
}
```

동작 추적:
```
factorial(4) = 4 * factorial(3)
             = 4 * 3 * factorial(2)
             = 4 * 3 * 2 * factorial(1)
             = 4 * 3 * 2 * 1 = 24
```

> 종료 조건이 없으면 무한 재귀 → **스택 오버플로** → 크래시.

---

### 6. 반복 vs 재귀

| 기준 | 반복 | 재귀 |
|------|------|------|
| 메모리 | 효율적 | 스택 프레임 누적 |
| 가독성 | 단순 반복에 좋음 | 분할 구조에 명료 |
| 위험 | 무한 루프 | 스택 오버플로 |

피보나치 재귀는 같은 값을 중복 계산해 느리다 (`fib_rec(40)` 체감). 반복 버전은 빠르다.

---

## 실습 코드

**factorial.c 핵심**:
```c
int fact_rec(int n)
{
    if (n <= 1)
        return (1);
    return (n * fact_rec(n - 1));
}
```

**fibonacci.c 반복 버전 핵심**:
```c
prev = 0; curr = 1;
while (i <= n) { next = prev + curr; prev = curr; curr = next; i++; }
return (curr);
```

## 트러블슈팅

| 증상 | 확인 사항 |
|------|----------|
| `implicit declaration of function` | 프로토타입 누락. main 위에 선언 |
| 재귀가 멈추지 않고 크래시 | 종료 조건 없음 또는 조건에 도달 못함 |
| 함수 안에서 바꿨는데 원본이 그대로 | 정상! 값 전달은 복사. 포인터 필요 |
| `control reaches end of non-void function` | 모든 경로에서 return 했는지 확인 |
| 피보나치 재귀가 너무 느림 | 중복 계산. 반복 버전 사용 또는 메모이제이션 |
