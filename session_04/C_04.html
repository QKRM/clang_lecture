함수(Function)란?

한 줄 정의

입력을 받아 일을 하고 결과를 돌려주는 코드 묶음

반복을 줄이고, 코드를 의미 단위로 나눠 읽기 쉽게 만듭니다.

main도 함수다

지금까지 쓴 main도 함수. int 반환, return (0)은 정상 종료를 뜻함.

함수의 구조 
// 반환타입  이름(매개변수)
int add(int a, int b)
{
    return (a + b);  // 반환값
}
int반환 타입
add함수 이름
a, b매개변수 (입력)
return반환값 + 함수 종료

/* 2. 정의 */
int add(int a, int b)
{
    return (a + b);

왜 프로토타입?

C는 위에서 아래로 읽습니다. main 아래 정의한 함수를 호출하려면, 미리 "이런 함수가 있다"고 선언해야 합니다.

프로토타입 규칙

  • ✓세미콜론으로 끝남 (본문 없음)
  • ✓매개변수 이름 생략 가능: int add(int, int);
  • ✗없으면 implicit declaration 경고

반환값과 매개변수 — void 활용

/* 매개변수 없음, 반환값 있음 */

void의 두 가지 의미

  • →반환 타입 void: 돌려줄 값 없음
  • →매개변수 (void): 받을 입력 없음

return; 단독 사용

void 함수에서 return;만 쓰면 값 없이 즉시 종료. 조건에 따라 일찍 빠져나갈 때 유용.

Slide 06 / Pass by Value 4차시: 함수와 재귀

값에 의한 전달 (Pass by Value)

인자를 넘기면 값이 복사됩니다. 함수 안에서 바꿔도 원본은 그대로.

void try_change(int x)
{
    x = 100;  // 복사본만 변경
}

int main(void)
{
    int a = 5;
    try_change(a);
    printf("%d\n", a);  // 5 (안 바뀜!)
}

그럼 원본은 어떻게 바꾸나?

주소를 넘기면 됩니다. 이것이 포인터 — 5차시의 핵심:

/* 미리보기 — 5차시 상세 */
void swap(int *a, int *b)
{
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

지금은 "기본 전달은 복사다"만 확실히 기억하세요.

Slide 07 / Stack Frame 4차시: 함수와 재귀

스택 프레임 (Stack Frame)

함수를 호출할 때마다 스택에 프레임이 쌓이고, return 시 제거됩니다.

main() 호출  → [main]
 add() 호출  → [main][add]
 add() 반환  → [main]
main() 반환  → (비어 있음)

프레임 = 그 함수의 지역 변수 + 매개변수

지역 변수의 수명

int make(void)
{
    int local = 10;
    return (local);
    // 값은 복사 반환 (안전)
}

함수가 끝나면 지역 변수는 사라진다. 주소를 반환하면 위험 (사라진 메모리).

스택은 한정된 공간. 재귀가 너무 깊으면 넘침(스택 오버플로) → 다음 슬라이드.

Slide 08 / Recursion 4차시: 함수와 재귀

재귀 — 자기 자신을 호출

반드시 두 가지가 필요 
int factorial(int n)
{
    if (n <= 1)
        return (1);
        // ↑ 종료 조건 (base case)

    return (n * factorial(n - 1));
        // ↑ 재귀 호출 (더 작은 문제)
}

두 요소

  • 1종료 조건 — 재귀를 멈추는 지점
  • 2재귀 호출 — 자신을 더 작게 호출

종료 조건이 없으면?

int bad(int n)
{
    return (bad(n - 1));
}  // 무한 재귀 → 크래시

스택 오버플로로 프로그램이 죽는다.

Slide 09 / Trace 4차시: 함수와 재귀

재귀 동작 추적 — factorial(4)

펼쳐지는 과정 (호출) 
factorial(4)
= 4 * factorial(3)
= 4 * (3 * factorial(2))
= 4 * (3 * (2 * factorial(1)))
= 4 * (3 * (2 * 1))
         ↑ 종료 조건 도달
접히는 과정 (반환) 
= 4 * (3 * (2 * 1))
= 4 * (3 * 2)
= 4 * 6
= 24

각 호출이 스택 프레임을 쌓고, 종료 조건에 닿으면 거꾸로 계산되며 프레임이 풀립니다.

실습 2 — 팩토리얼 factorial.c

두 버전을 모두 구현 
/* 반복 */
int fact_loop(int n)
{
    int result = 1;
    for (int i = 2; i <= n; i++)
        result *= i;
    return (result);
}

/* 재귀 */
int fact_rec(int n)
{
    if (n <= 1)
        return (1);
    return (n * fact_rec(n - 1));
}

요구사항

1~5에 대해 두 함수 결과가 같은지 출력

n=1  loop=1   rec=1
n=2  loop=2   rec=2
n=3  loop=6   rec=6
n=4  loop=24  rec=24
n=5  loop=120 rec=120

실습 3 — 피보나치 fibonacci.c

fib(0)=0, fib(1)=1, fib(n)=fib(n-1)+fib(n-2)

/* 재귀 */
int fib_rec(int n)
{
    if (n < 2)
        return (n);
    return (fib_rec(n - 1)
          + fib_rec(n - 2));
}

요구사항

  • ✓fib_loop(반복) + fib_rec(재귀)
  • ✓0~10 출력
