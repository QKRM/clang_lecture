함수와 재귀

학습 목표

  1. 함수를 선언(프로토타입), 정의, 호출할 수 있다.
  2. 매개변수와 반환값의 역할을 설명할 수 있다.
  3. 값에 의한 전달(pass by value)을 이해한다.
  4. 스택 프레임 개념으로 함수 호출 과정을 설명할 수 있다.
  5. 재귀 함수의 동작 원리를 설명하고 구현할 수 있다.

1부: 함수란?

1.1 함수의 정의

입력(매개변수)을 받아 어떤 일을 하고 결과(반환값)를 돌려주는 코드 묶음입니다. 같은 일을 여러 번 할 때 반복을 줄이고, 코드를 의미 단위로 나눕니다.

//  반환타입  함수이름(매개변수 목록)
int add(int a, int b)
{
    return (a + b);   // 반환값
}
구성 요소설명
반환 타입함수가 돌려주는 값의 타입 (void면 없음)
함수 이름호출할 때 쓰는 이름 (snake_case 권장)
매개변수함수가 받는 입력 (없으면 void)
반환값return으로 돌려주는 결과

1.2 main도 함수다

지금까지 쓴 main도 함수입니다. int를 반환하며, return (0)은 "정상 종료"를 뜻합니다.

int main(void)
{
    return (0);   // 0 = 성공
}

2부: 함수 선언·정의·호출

2.1 세 가지 단계

#include <stdio.h>

/* 1. 선언 (프로토타입) — "이런 함수가 있다"고 컴파일러에 알림 */
int add(int a, int b);

int main(void)
{
    /* 3. 호출 — 실제로 사용 */
    int result = add(3, 5);
    printf("%d\n", result);   // 8
    return (0);
}

/* 2. 정의 — 함수의 실제 내용 */
int add(int a, int b)
{
    return (a + b);
}

2.2 프로토타입이 왜 필요한가?

C는 위에서 아래로 읽습니다. main보다 아래에 정의된 함수를 main에서 호출하려면, 미리 프로토타입으로 알려야 합니다. 알리지 않으면 경고/에러가 발생합니다.

int add(int a, int b);   // 세미콜론으로 끝남 (본문 없음)
매개변수 이름은 프로토타입에서 생략 가능: int add(int, int);

2.3 void 활용

/* 반환값 없음 */
void print_line(void)
{
    printf("----------\n");
}

/* 매개변수 없음, 반환값 있음 */
int get_answer(void)
{
    return (42);
}

return;만 쓰면 (값 없이) 함수를 즉시 종료할 수 있습니다.

3부: 값에 의한 전달 (Pass by Value)

3.1 복사본이 전달된다

함수에 인자를 넘기면 값이 복사됩니다. 함수 안에서 매개변수를 바꿔도 원본은 그대로입니다.

void try_change(int x)
{
    x = 100;   // 복사본만 변경
}

int main(void)
{
    int a = 5;
    try_change(a);
    printf("%d\n", a);   // 5 (변하지 않음!)
    return (0);
}

3.2 그럼 어떻게 원본을 바꾸나?

주소를 넘기면 됩니다. 이것이 포인터이며 5차시의 핵심 주제입니다.

/* 미리보기 — 포인터로 swap (5차시 상세) */
void swap(int *a, int *b)
{
    int tmp = *a;
    *a = *b;
    *b = tmp;
}
지금은 "기본 전달은 복사다"만 확실히 기억하면 됩니다.

4부: 스택 프레임

4.1 함수 호출과 스택

함수를 호출할 때마다 메모리의 스택(stack) 영역에 "스택 프레임"이 쌓입니다. 프레임에는 그 함수의 지역 변수와 매개변수가 담깁니다. 함수가 끝나면(return) 프레임이 제거됩니다.

main() 호출       → [main 프레임]
 add() 호출       → [main][add]
 add() 반환       → [main]          (add 프레임 제거)
main() 반환       → (비어 있음)

4.2 지역 변수의 수명

함수 안에서 선언한 변수는 그 함수가 실행되는 동안만 살아있습니다. 함수가 끝나면 사라집니다.

int make(void)
{
    int local = 10;   // make가 끝나면 사라짐
    return (local);   // 값은 복사되어 반환됨 (안전)
}
지역 변수의 주소를 반환하면 위험합니다 (사라진 메모리를 가리킴). 5차시 포인터, 11차시 동적 메모리에서 자세히 다룹니다.

5부: 재귀 (Recursion)

5.1 재귀란?

함수가 자기 자신을 호출하는 것입니다. 반드시 두 가지가 필요합니다:

  1. 종료 조건 (base case) — 더 이상 재귀하지 않고 끝나는 지점
  2. 재귀 호출 (recursive case) — 자기 자신을 더 작은 문제로 호출
int factorial(int n)
{
    if (n <= 1)              // 종료 조건
        return (1);
    return (n * factorial(n - 1));  // 재귀 호출
}

5.2 동작 추적 (factorial(4))

factorial(4) = 4 * factorial(3)
             = 4 * (3 * factorial(2))
             = 4 * (3 * (2 * factorial(1)))
             = 4 * (3 * (2 * 1))
             = 24

각 호출이 스택 프레임을 쌓고, 종료 조건에 닿으면 거꾸로 계산되며 프레임이 풀립니다.

5.3 종료 조건이 없으면?

스택 프레임이 무한히 쌓여 스택 오버플로(stack overflow)가 발생하고 프로그램이 죽습니다.

int bad(int n)
{
    return (bad(n - 1));   // 종료 조건 없음 → 무한 재귀 → 크래시
}

5.4 반복 vs 재귀

기준반복(for/while)재귀
속도/메모리효율적함수 호출 비용 + 스택 사용
가독성단순 반복에 적합분할 구조(트리, 분할정복)에 명료
위험무한 루프스택 오버플로
같은 문제를 두 방식으로 모두 풀 수 있어야 합니다. 실습에서 직접 비교합니다.

핵심 정리

  1. 함수 = 반환타입 + 이름 + 매개변수 + 본문
  2. main 아래 정의된 함수는 프로토타입으로 미리 선언
  3. 인자는 값으로 복사되어 전달 — 원본은 안 바뀜
  4. 함수 호출마다 스택 프레임이 쌓이고 반환 시 제거
  5. 재귀는 종료 조건 + 재귀 호출 두 가지가 필수
  6. 종료 조건이 없으면 스택 오버플로로 크래시

다음 차시 예고

5차시에서는 포인터 기초를 학습합니다. 메모리 주소, &(주소 연산자), *(역참조 연산자)를 다루고, 오늘 미리 본 swap 함수를 포인터로 직접 구현합니다. "값 전달의 한계를 포인터로 넘는다"가 핵심입니다.

과제 2: 팩토리얼 — 반복 vs 재귀

factorial.c 파일을 만들고 두 가지 버전을 모두 구현하세요.

요구사항:

  • int fact_loop(int n) — for 또는 while 반복
  • int fact_rec(int n) — 재귀
  • main에서 1~5에 대해 두 함수 결과가 같은지 출력

출력 예시:

n=1  loop=1   rec=1
n=2  loop=2   rec=2
n=3  loop=6   rec=6
n=4  loop=24  rec=24
n=5  loop=120 rec=120

힌트:

int fact_loop(int n)
{
    int result = 1;
    for (int i = 2; i <= n; i++)
        result *= i;
    return (result);
}

int fact_rec(int n)
{
    if (n <= 1)
        return (1);
    return (n * fact_rec(n - 1));
}

  • int fib_loop(int n) — 반복

📄 factorial.c
#include <stdio.h>

int	fact_loop(int n);
int	fact_rec(int n);

int	main(void)
{
	int	n;

	n = 1;
	while (n <= 5)
	{
		printf("n=%d  loop=%d  rec=%d\n", n, fact_loop(n), fact_rec(n));
		n++;
	}
	return (0);
}

int	fact_loop(int n)
{
	int	result;
	int	i;

	result = 1;
	i = 2;
	while (i <= n)
	{
		result *= i;
		i++;
	}
	return (result);
}

int	fact_rec(int n)
{
	if (n <= 1)
		return (1);
	return (n * fact_rec(n - 1));
}
📄 fibonacci.c
#include <stdio.h>

int	fib_loop(int n);
int	fib_rec(int n);

int	main(void)
{
	int	n;

	n = 0;
	while (n <= 10)
	{
		printf("fib(%d) = %d  (rec=%d)\n", n, fib_loop(n), fib_rec(n));
		n++;
	}
	return (0);
}

int	fib_loop(int n)
{
	int	prev;
	int	curr;
	int	next;
	int	i;

	if (n < 2)
		return (n);
	prev = 0;
	curr = 1;
	i = 2;
	while (i <= n)
	{
		next = prev + curr;
		prev = curr;
		curr = next;
		i++;
	}
	return (curr);
}

int	fib_rec(int n)
{
	if (n < 2)
		return (n);
	return (fib_rec(n - 1) + fib_rec(n - 2));
}
