Slide 03 / Truthiness 3차시: 조건문과 반복문

C에서 참과 거짓

한 줄 정의

0은 거짓, 0이 아닌 모든 값은 참

C에는 기본 boolean 타입이 없습니다. 조건식의 결과가 0이면 거짓, 그 외면 참으로 처리합니다.

자주 하는 실수

  • →if (x = 5)는 대입! 항상 참이 됨 (의도는 ==)
  • →비교 결과는 1(참) 또는 0(거짓) 정수값
if (1)   printf("항상 실행\n");  // 참
if (0)   printf("실행 안 됨\n");  // 거짓
if (-5)  printf("실행됨\n");      // 참 (0 아님)

/* 비교 결과는 정수 1 또는 0 */
int r = (5 > 3);   // r = 1
int q = (5 == 3);  // q = 0

libsbs에서 while (str[i])는 "문자가 '\0'(=0)이 아닌 동안 반복"이라는 뜻입니다.

switch — break를 잊지 마라

switch (day)
{
    case 1:
        printf("월\n");
        break;
    case 2:
        printf("화\n");
        break;
    default:
        printf("기타\n");
}

break 없으면 fall-through

case 1:
case 2:
case 3:
    printf("1~3\n");
    break;  // 1,2,3 모두 여기로

✓ 비교 대상은 정수형(int, char)만

✓ case 라벨은 상수만 가능

✓ default는 어디에도 안 맞을 때

Slide 06 / while 3차시: 조건문과 반복문

while — 조건이 참인 동안 반복

int i = 0;

while (i < 5)
{
    printf("%d ", i);  // 0 1 2 3 4
    i++;  // ← 이걸 빠뜨리면 무한 루프!
}

무한 루프 주의

조건을 거짓으로 만드는 코드(i++)가 없으면 프로그램이 멈추지 않습니다.

libsbs에서 가장 흔한 패턴

길이를 미리 모르는 문자열을 순회할 때:

/* sbs_strlen 의 뼈대 */
size_t i = 0;

while (s[i] != '\0')
    i++;
return (i);

'\0'(null 문자, 값 0)을 만날 때까지 세는 것이 문자열 길이입니다.

Slide 07 / for 3차시: 조건문과 반복문

for — 횟수가 정해진 반복

//   초기화;    조건;   증감
for (int i = 0; i < 5; i++)
{
    printf("%d ", i);  // 0 1 2 3 4
}
실행 순서
  1. 1초기화 — 딱 한 번
  2. 2조건 검사 — 거짓이면 종료
  3. 3본문 실행
  4. 4증감 후 2번으로 돌아감

for와 while은 서로 변환 가능. 횟수가 명확하면 for가 읽기 좋다.

Slide 08 / do-while 3차시: 조건문과 반복문

do-while & 어떤 반복문을 쓸까?

do-while — 최소 1회 실행 
int i = 10;

do {
    printf("%d ", i);  // 10 출력
    i++;
} while (i < 5);  // 조건 거짓이어도 1회 실행

끝에 세미콜론(;) 필수. 본문을 먼저 실행 후 조건 검사.

상황별 선택
상황 추천
횟수가 정해짐 (0~n)for
조건 기반 (입력/탐색)while
최소 1회 보장 (메뉴)do-while

libsbs는 길이를 모르는 데이터를 다루므로 while이 압도적으로 많습니다.

Slide 09 / break & continue 3차시: 조건문과 반복문

흐름 제어 — break & continue

break — 반복문 전체 종료 
for (int i = 0; i < 100; i++)
{
    if (i == 5)
        break;
    printf("%d ", i);
}
// 출력: 0 1 2 3 4
continue — 현재 회차만 건너뜀 
for (int i = 0; i < 10; i++)
{
    if (i % 2 == 0)
        continue;
    printf("%d ", i);
}
// 출력: 1 3 5 7 9
키워드 동작
break가장 가까운 반복문(또는 switch)을 즉시 종료
continue이번 회차의 나머지를 건너뛰고 다음 회차로
