변수, 자료형, 연산자

2차시 강의 노트 - 변수, 자료형, 연산자

학습 목표

  1. C언어의 기본 자료형(int, char, float, double)의 크기와 범위를 설명할 수 있다.
  2. 변수를 선언하고 초기화하는 방법을 안다.
  3. 산술, 비교, 논리 연산자를 올바르게 사용할 수 있다.
  4. 암묵적/명시적 형 변환의 차이를 이해한다.

1부: 자료형 (Data Types)

1.1 자료형이란?

변수에 저장할 수 있는 데이터의 종류와 크기를 정의하는 것입니다. 컴퓨터 메모리는 한정되어 있으므로, 어떤 종류의 값을 저장할지 미리 지정해야 합니다.

1.2 기본 자료형

자료형크기범위용도
char1 바이트-128 ~ 127 (또는 0 ~ 255)문자 1개 저장
int4 바이트-2,147,483,648 ~ 2,147,483,647정수
long8 바이트매우 큰 정수 범위큰 정수
float4 바이트소수점 약 7자리 정밀도실수
double8 바이트소수점 약 15자리 정밀도정밀한 실수

중요: 크기는 시스템과 컴파일러에 따라 다를 수 있습니다. sizeof 연산자로 직접 확인하는 것이 정확합니다.

#include <stdio.h>

int main(void)
{
    printf("char   크기: %zu 바이트\n", sizeof(char));
    printf("int    크기: %zu 바이트\n", sizeof(int));
    printf("long   크기: %zu 바이트\n", sizeof(long));
    printf("float  크기: %zu 바이트\n", sizeof(float));
    printf("double 크기: %zu 바이트\n", sizeof(double));
    return (0);
}
참고: %zu는 sizeof의 반환 타입인 size_t를 출력하는 서식 지정자입니다.

1.3 unsigned 수식어

unsigned를 붙이면 음수를 저장하지 않는 대신 양수 범위가 두 배로 늘어납니다.

자료형범위
unsigned char0 ~ 255
unsigned int0 ~ 4,294,967,295

libsbs 에서 중요: 많은 표준 라이브러리 함수의 매개변수가 unsigned char나 size_t를 사용합니다. 이를 이해해야 함수 명세를 정확히 구현할 수 있습니다.

1.4 size_t

size_t는 크기를 나타내는 특수한 자료형입니다. sizeof의 반환 타입이기도 합니다.

#include <stddef.h>  // size_t 정의

size_t length = 10;

2부: 변수 선언과 초기화

2.1 변수 선언

자료형 변수명;
자료형 변수명 = 초기값;
int age;           // 선언만 (초기화 안 됨 - 쓰레기값 주의!)
int score = 100;   // 선언과 동시에 초기화
char grade = 'A';  // 문자는 작은따옴표
double pi = 3.14;  // 실수

2.2 변수 명명 규칙

  • 영문자, 숫자, 밑줄(_)만 사용 가능
  • 숫자로 시작 불가
  • C언어 예약어(int, if, for 등) 사용 불가
  • 대소문자 구분 (age와 Age는 다른 변수)

권장 스타일 (Snake case):

int student_count = 30;
char first_name = 'J';

2.3 상수 (const)

값이 변하지 않는 변수는 const로 선언합니다.

const int MAX_SIZE = 1024;
const double PI = 3.141592653589793;

const 변수에 값을 재대입하려 하면 컴파일 에러가 발생합니다.

3부: 연산자

3.1 산술 연산자

int a = 10;
int b = 3;

printf("%d\n", a + b);  // 덧셈: 13
printf("%d\n", a - b);  // 뺄셈: 7
printf("%d\n", a * b);  // 곱셈: 30
printf("%d\n", a / b);  // 나눗셈(정수): 3 (소수점 버림!)
printf("%d\n", a % b);  // 나머지: 1

정수 나눗셈 주의: int / int = int (소수점 이하 버림)

int result = 10 / 3;    // 결과: 3 (3.33...이 아님)
double result2 = 10.0 / 3;  // 결과: 3.333... (하나라도 실수면 실수 나눗셈)

3.2 증감 연산자

int x = 5;

x++;   // x를 1 증가 (후위: 현재 값 사용 후 증가)
++x;   // x를 1 증가 (전위: 먼저 증가 후 사용)
x--;   // x를 1 감소
--x;   // x를 1 감소

// 전위 vs 후위 차이
int a = 5;
int b = a++;  // b = 5, a = 6 (b에 5를 먼저 대입 후 a 증가)
int c = ++a;  // a = 7, c = 7 (a를 먼저 증가 후 c에 대입)

3.3 대입 연산자

int x = 10;

x += 5;   // x = x + 5;  → x = 15
x -= 3;   // x = x - 3;  → x = 12
x *= 2;   // x = x * 2;  → x = 24
x /= 4;   // x = x / 4;  → x = 6
x %= 4;   // x = x % 4;  → x = 2

3.4 비교 연산자

결과는 참(1) 또는 거짓(0)입니다.

int a = 5, b = 3;

printf("%d\n", a == b);  // 같음: 0 (거짓)
printf("%d\n", a != b);  // 다름: 1 (참)
printf("%d\n", a > b);   // 큼: 1
printf("%d\n", a < b);   // 작음: 0
printf("%d\n", a >= b);  // 크거나 같음: 1
printf("%d\n", a <= b);  // 작거나 같음: 0

3.5 논리 연산자

int x = 1, y = 0;

printf("%d\n", x && y);  // AND: 둘 다 참이어야 참 → 0
printf("%d\n", x || y);  // OR: 하나라도 참이면 참 → 1
printf("%d\n", !x);      // NOT: 참이면 거짓, 거짓이면 참 → 0

3.6 연산자 우선순위 (중요!)

높을수록 먼저 계산됩니다.

1. () 괄호
2. 단항 연산자: !, ++, --, (type)
3. *, /, %
4. +, -
5. <, >, <=, >=
6. ==, !=
7. &&
8. ||
9. =, +=, -=, ...

헷갈리면 항상 괄호를 사용하세요!

// 아래 두 줄의 결과가 다릅니다
int result1 = 2 + 3 * 4;    // 14 (곱셈 먼저)
int result2 = (2 + 3) * 4;  // 20 (괄호 먼저)

4부: 형 변환 (Type Casting)

4.1 암묵적 형 변환 (Implicit)

컴파일러가 자동으로 타입을 변환합니다.

int i = 10;
double d = i;  // int → double 자동 변환 (값: 10.0)

double x = 3.7;
int n = x;     // double → int 자동 변환 (값: 3, 소수점 버림!) 경고 발생!

4.2 명시적 형 변환 (Explicit, Casting)

프로그래머가 직접 타입을 지정합니다.

int a = 10, b = 3;

// 정수 나눗셈을 실수 나눗셈으로 바꾸기
double result = (double)a / b;  // 3.333...

libsbs 에서 중요: memset, memcpy 등의 함수에서 void *를 unsigned char *로 캐스팅하는 경우가 많습니다. 이 개념이 나중에 핵심이 됩니다.

핵심 정리

  1. char(1B), int(4B), double(8B)이 가장 자주 쓰이는 자료형
  2. 정수 나눗셈은 소수점을 버린다 → 실수 나눗셈이 필요하면 하나를 double로 캐스팅
  3. sizeof(자료형)으로 실제 크기를 직접 확인할 수 있다
  4. unsigned는 음수를 포기하고 양수 범위를 두 배로 확장
  5. 연산자 우선순위가 헷갈리면 괄호를 사용

다음 차시 예고

3차시에서는 조건문(if, switch)과 반복문(for, while)을 학습합니다. 구구단, FizzBuzz 등의 프로그램을 직접 구현합니다.

과제 3: 온도 변환기

temperature.c 파일을 만들고 섭씨를 화씨로, 화씨를 섭씨로 변환하는 프로그램을 작성하세요.

공식:

  • 섭씨 → 화씨: F = C * 9.0 / 5.0 + 32
  • 화씨 → 섭씨: C = (F - 32) * 5.0 / 9.0

요구사항:

  • 섭씨 0도, 100도를 화씨로 변환
  • 화씨 32도, 212도를 섭씨로 변환
  • 소수점 2자리까지 출력 (%.2f)

출력 예시:

섭씨 0.00°C = 화씨 32.00°F
섭씨 100.00°C = 화씨 212.00°F
화씨 32.00°F = 섭씨 0.00°C
화씨 212.00°F = 섭씨 100.00°C

과제 4: 연산자 우선순위 실험 (심화, 20분)

priority.c 파일을 만들고 아래 식의 결과를 먼저 손으로 계산한 뒤, 프로그램으로 확인하세요.

#include <stdio.h>

int main(void)
{
    int a = 2, b = 3, c = 4;
    int result;

    // 각 식의 결과를 예상하고 출력하세요
    result = a + b * c;
    printf("a + b * c = %d\n", result);

    result = (a + b) * c;
    printf("(a + b) * c = %d\n", result);

    result = a * b + c * 2;
    printf("a * b + c * 2 = %d\n", result);

    result = a + b > c;
    printf("a + b > c = %d\n", result);

    result = a == 2 && b == 3;
    printf("a == 2 && b == 3 = %d\n", result);

    result = a > 1 || b > 10;
    printf("a > 1 || b > 10 = %d\n", result);

    return (0);
}

📄 temperature.c
#include <stdio.h>

int main(void)
{
	double celsius;
	double fahrenheit;

	printf("=== 온도 변환기 ===\n\n");
	printf("[ 섭씨 → 화씨 ]  공식: F = C * 9.0 / 5.0 + 32\n");
	celsius = 0.0;
	fahrenheit = celsius * 9.0 / 5.0 + 32;
	printf("섭씨 %6.2f°C = 화씨 %6.2f°F\n", celsius, fahrenheit);
	celsius = 100.0;
	fahrenheit = celsius * 9.0 / 5.0 + 32;
	printf("섭씨 %6.2f°C = 화씨 %6.2f°F\n", celsius, fahrenheit);
	celsius = 37.0;
	fahrenheit = celsius * 9.0 / 5.0 + 32;
	printf("섭씨 %6.2f°C = 화씨 %6.2f°F  (체온)\n", celsius, fahrenheit);
	printf("\n[ 화씨 → 섭씨 ]  공식: C = (F - 32) * 5.0 / 9.0\n");
	fahrenheit = 32.0;
	celsius = (fahrenheit - 32) * 5.0 / 9.0;
	printf("화씨 %6.2f°F = 섭씨 %6.2f°C\n", fahrenheit, celsius);
	fahrenheit = 212.0;
	celsius = (fahrenheit - 32) * 5.0 / 9.0;
	printf("화씨 %6.2f°F = 섭씨 %6.2f°C\n", fahrenheit, celsius);
	fahrenheit = 98.6;
	celsius = (fahrenheit - 32) * 5.0 / 9.0;
	printf("화씨 %6.2f°F = 섭씨 %6.2f°C  (체온)\n", fahrenheit, celsius);
	return (0);
}
