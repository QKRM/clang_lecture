자료형(Data Type)이란?

한 줄 정의

메모리에 어떤 종류의 값을 얼마나 담을지 정하는 것

컴파일러는 자료형을 보고 메모리를 얼마나 예약할지, 비트 패턴을 어떻게 해석할지 결정합니다.

왜 중요한가?

  • →같은 비트 패턴이라도 타입에 따라 해석이 다름
  • →char c = 65;는 숫자 65지만 %c로 출력하면 'A'
  • →libsbs에서 메모리를 바이트 단위로 다룰 때 타입이 결정적
기본 자료형 한눈에 보기
자료형 크기 용도
char1 B문자 1개, 작은 정수
int4 B일반 정수
long8 B큰 정수
float4 B실수 (7자리 정밀도)
double8 B정밀한 실수 (15자리)

크기는 시스템마다 다를 수 있음 → sizeof로 직접 확인이 정확

#include <stdio.h>

int main(void)
{
    printf("char   : %zu 바이트\n", sizeof(char));
    printf("int    : %zu 바이트\n", sizeof(int));
    printf("long   : %zu 바이트\n", sizeof(long));
    printf("float  : %zu 바이트\n", sizeof(float));
    printf("double : %zu 바이트\n", sizeof(double));
    printf("int*   : %zu 바이트\n", sizeof(int *));
    return (0);
}

%zu 포맷

sizeof의 반환 타입은 size_t입니다. %zu를 써야 경고 없이 출력됩니다. %d를 쓰면 -Wformat 경고 발생!

size_t

size_t len = sizeof(int);   // 4

libsbs에서 왜 중요한가?

man page를 보면 표준 함수들이 이 타입을 씁니다:

/* man 3 memset */
void *memset(void *s, int c, size_t n);

/* man 3 strlen */
size_t strlen(const char *s);

/* man 3 memcpy */
void *memcpy(void *dst, const void *src, size_t n);

이 함수들을 구현할 때 size_t와 unsigned char *를 그대로 써야 명세에 맞는 정확한 구현이 됩니다.

Slide 07 / Arithmetic 2차시: 변수, 자료형, 연산자

산술 연산자

int a = 17;
int b = 5;

printf("%d\n", a + b);  // 덧셈: 22
printf("%d\n", a - b);  // 뺄셈: 12
printf("%d\n", a * b);  // 곱셈: 85
printf("%d\n", a / b);  // 정수 나눗셈: 3 ⚠
printf("%d\n", a % b);  // 나머지: 2

정수 나눗셈 함정

int / int = int  (소수점 버림!)
17 / 5 = 3  (3.4가 아님)

실수 나눗셈으로 바꾸려면

// 방법 1: 리터럴을 실수로
double r = 17.0 / 5;    // 3.4

// 방법 2: 명시적 형 변환
double r = (double)a / b; // 3.4

나머지 연산자 %

  • →짝수 판별: n % 2 == 0
  • →순환 인덱스: i % size
  • →libsbs: 버퍼 크기 계산에 자주 등장

Slide 11 / Implicit Cast 2차시: 변수, 자료형, 연산자

형 변환 1 — 암묵적(Implicit) 변환

컴파일러가 자동으로 타입을 변환합니다. 작은 타입 → 큰 타입은 안전, 반대는 위험.

/* 안전: 작은 → 큰 (정보 손실 없음) */
int    i = 10;
double d = i;     // 10 → 10.0  OK

/* 위험: 큰 → 작은 (정보 손실!) */
double x = 3.7;
int    n = x;     // 3.7 → 3  소수점 버림!
                  // -Wconversion 경고 발생

/* char ↔ int (자주 쓰는 패턴) */
char c = 'A';
int  n = c;       // n = 65  (ASCII 코드)

char ↔ int 변환 — libsbs 핵심!

char c = 'A';
printf("%c", c);   // A
printf("%d", c);   // 65
printf("%d", c + 1); // 66 = 'B'

문자와 숫자는 같은 메모리 — 해석만 다름. isalpha, toupper 구현의 기초.

산술 변환 규칙: 연산 시 더 큰 타입으로 자동 통일됨. int + double이면 결과는 double.

형 변환 2 — 명시적(Explicit) 캐스팅

프로그래머가 직접 타입을 지정합니다. 문법: (타입)값

int a = 10, b = 3;

/* 정수 나눗셈 → 실수 나눗셈 */
double r = (double)a / b;  // 3.333...

/* int → char (truncation) */
int  n = 65;
char c = (char)n;  // 'A'

/* void* → 특정 포인터 타입 */
void *ptr = &a;
int  *ip  = (int *)ptr;

libsbs 구현에서의 캐스팅

표준 함수들은 void *를 받아 내부에서 바이트 단위로 처리합니다:

/* sbs_memset 구현 예시 */
void *sbs_memset(void *s, int c, size_t n)
{
    unsigned char *ptr;

    ptr = (unsigned char *)s;
    while (n--)
        *ptr++ = (unsigned char)c;
    return (s);
}

void *는 어떤 타입이든 받을 수 있는 범용 포인터. 바이트 단위 처리를 위해 unsigned char *로 캐스팅.

범위 문자 의미

문자 연산 패턴 
/* 대소문자 판별 */
c >= 'A' && c <= 'Z'   → 대문자
c >= 'a' && c <= 'z'   → 소문자

/* 대 ↔ 소 변환 */
c + 32   → 대문자를 소문자로
c - 32   → 소문자를 대문자로

/* 숫자 문자 → 정수 */
'5' - '0'  → 5  (atoi의 핵심)
