# 5차시 심화 - 포인터 한 걸음 더

> 기본(주소·역참조·swap)을 끝낸 학생을 위한 심화 자료입니다. 시간이 남거나 이해가 빠른 경우 다룹니다. 6차시(배열)·10차시(메모리 함수) 이전에 알아두면 좋은 내용입니다.

## 심화 학습 목표

1. 출력 매개변수로 함수가 여러 값을 "반환"하게 만들 수 있다.
2. `const` 포인터로 읽기 전용 의도를 표현할 수 있다.
3. 이중 포인터(`int **`)의 개념을 이해한다.
4. 포인터 타입에 따라 `+1`의 이동 폭이 다름을 설명할 수 있다.
5. 지역 변수 주소 반환이 왜 위험한지 설명할 수 있다.

---

## 1. 출력 매개변수 (Output Parameter)

### 1.1 함수는 값 하나만 반환한다

`return`은 값을 하나만 돌려줍니다. 두 개 이상을 돌려주고 싶을 때 포인터를 씁니다. 결과를 담을 변수의 **주소**를 미리 넘기는 방식입니다.

```c
/* 몫과 나머지를 한 번에 구하기 */
void divmod(int a, int b, int *quot, int *rem)
{
    *quot = a / b;   // 몫을 호출자의 변수에 직접 씀
    *rem = a % b;    // 나머지도
}

int main(void)
{
    int q, r;
    divmod(17, 5, &q, &r);          // 결과 담을 주소를 넘김
    printf("몫=%d 나머지=%d\n", q, r);  // 몫=3 나머지=2
    return (0);
}
```

> swap도 출력 매개변수의 한 형태입니다. "함수가 호출자의 변수를 직접 고친다"는 점이 같습니다.

### 1.2 min/max 동시에 구하기

```c
void min_max(int a, int b, int *min, int *max)
{
    if (a < b)
    {
        *min = a;
        *max = b;
    }
    else
    {
        *min = b;
        *max = a;
    }
}
```

## 2. const 포인터 — 읽기 전용 의도

### 2.1 가리키는 값을 바꾸지 못하게

`const`를 붙이면 "이 포인터로는 값을 수정하지 않겠다"는 약속입니다. 실수로 바꾸면 컴파일 에러로 막아줍니다.

```c
void print_value(const int *p)
{
    printf("%d\n", *p);   // 읽기 — OK
    // *p = 100;          // 에러! const라 수정 불가
}
```

### 2.2 왜 쓰나?

읽기만 하는 함수에 `const`를 붙이면 의도가 분명해지고, 안전합니다. libsbs의 `sbs_strlen`, `sbs_memcmp` 같은 "읽기만 하는" 함수가 `const`를 받습니다.

```c
/* 표준 strlen 시그니처 미리보기 (12차시) */
size_t sbs_strlen(const char *s);   // s를 읽기만 함
```

| 선언 | 의미 |
|------|------|
| `int *p` | 값 읽기/쓰기 모두 가능 |
| `const int *p` | p로는 값 읽기만 (수정 금지) |

## 3. 이중 포인터 (Pointer to Pointer)

### 3.1 포인터도 변수다 → 그 주소도 있다

포인터 `p`도 메모리에 사는 변수이므로 자신의 주소가 있습니다. 그 주소를 담는 것이 **이중 포인터**입니다.

```c
int n = 42;
int *p = &n;      // p는 n을 가리킴
int **pp = &p;    // pp는 p를 가리킴

printf("%d\n", n);       // 42
printf("%d\n", *p);      // 42 (p가 가리키는 값)
printf("%d\n", **pp);    // 42 (pp → p → n)
```

```
pp        p         n
[&p]  →  [&n]  →  [42]
```

`*pp`는 `p`(주소), `**pp`는 `n`(값)입니다. 한 단계씩 따라갑니다.

### 3.2 어디에 쓰나?

함수가 포인터 자체를 바꿔야 할 때 씁니다. 예: 함수 안에서 `malloc`한 메모리를 호출자의 포인터에 연결. 11차시 `sbs_calloc` 이후 동적 메모리에서 자연스럽게 만납니다.

```c
/* 호출자의 포인터를 함수가 설정 */
void alloc_it(int **out)
{
    *out = malloc(sizeof(int));   // 호출자 포인터에 주소 저장
    **out = 99;
}
```

> 지금은 "포인터의 주소도 담을 수 있다"는 개념만 잡으면 충분합니다.

## 4. 포인터 타입과 이동 폭

### 4.1 `+1`은 타입 크기만큼

포인터에 1을 더하면 "1바이트"가 아니라 **가리키는 타입의 크기**만큼 주소가 움직입니다.

```c
int    *pi;   // pi + 1  →  4바이트 이동 (int)
char   *pc;   // pc + 1  →  1바이트 이동 (char)
double *pd;   // pd + 1  →  8바이트 이동 (double)
```

이 덕분에 `*(p + i)`가 정확히 `i`번째 원소를 가리킵니다(6차시 배열의 핵심).

### 4.2 실험 코드

```c
int main(void)
{
    int    arr[3] = {10, 20, 30};
    int    *p = arr;

    printf("%p\n", (void *)p);       // 예: 0x...00
    printf("%p\n", (void *)(p + 1)); // 예: 0x...04  (+4)
    return (0);
}
```

> 포인터 자체의 크기(`sizeof(int *)`)는 보통 8바이트(64비트 시스템)로, 가리키는 타입과 무관하게 일정합니다. "주소를 담는 칸"의 크기이기 때문입니다.

## 5. 위험: 지역 변수 주소 반환

### 5.1 사라진 메모리를 가리키는 포인터

함수가 끝나면 지역 변수는 사라집니다(4차시 스택 프레임). 그 주소를 반환하면 **이미 사라진 메모리**를 가리키는 포인터가 됩니다.

```c
int *make_bad(void)
{
    int local = 10;
    return (&local);   // 위험! local은 곧 사라짐
}

int main(void)
{
    int *p = make_bad();
    printf("%d\n", *p);   // 정의되지 않은 동작 (쓰레기/크래시)
    return (0);
}
```

### 5.2 올바른 방법

- 값을 반환하거나(복사라 안전),
- 호출자가 만든 변수의 주소를 넘기거나(출력 매개변수),
- 동적 메모리(`malloc`)를 쓴다(11차시).

```c
/* 값 반환 — 안전 */
int make_good(void)
{
    int local = 10;
    return (local);   // 값이 복사되어 나감
}
```

## 심화 정리

1. 출력 매개변수: 결과 담을 **주소**를 넘겨 함수가 여러 값을 돌려준다
2. `const int *p`: 읽기 전용 의도 — 수정 시 컴파일 에러로 보호
3. 이중 포인터 `int **`: 포인터의 주소를 담는다 (`**pp`로 값 접근)
4. `p + 1`은 **타입 크기**만큼 이동 (int=4, char=1)
5. 지역 변수 주소 반환은 위험 — 값 반환/출력 매개변수/malloc 사용

---

## 심화 연결 지도

| 심화 주제 | 이어지는 차시 |
|-----------|---------------|
| 출력 매개변수 | 10~11차시 메모리 함수 (포인터로 결과 전달) |
| const 포인터 | 12차시 `sbs_strlen(const char *)` |
| 이중 포인터 | 11차시 이후 동적 메모리 |
| 포인터 타입/이동 폭 | 6차시 배열 순회, 7차시 문자열 |
| 지역 변수 수명 | 11차시 malloc/free |
