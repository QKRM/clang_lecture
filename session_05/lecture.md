# 5차시 강의 노트 - 포인터 기초

## 학습 목표

1. 메모리와 주소의 개념을 설명할 수 있다.
2. `&`(주소 연산자)와 `*`(역참조 연산자)를 사용할 수 있다.
3. 포인터를 선언하고 초기화할 수 있다.
4. 포인터를 통해 원본 값을 읽고 수정할 수 있다.
5. `swap` 함수를 포인터로 구현할 수 있다.

---

## 1부: 메모리와 주소

### 1.1 변수는 메모리 어딘가에 산다

변수를 선언하면 메모리(RAM)에 공간이 생기고, 그 공간에는 **주소(address)** 가 있습니다. 주소는 메모리의 번지수입니다.

```c
int n = 42;
```

`n`이라는 이름은 "42가 들어있는 어떤 주소"를 가리킵니다. 우리가 `n`을 쓰면 컴파일러가 그 주소에서 값을 꺼냅니다.

### 1.2 주소 연산자 `&`

변수 앞에 `&`를 붙이면 그 변수의 **주소**를 얻습니다.

```c
int n = 42;
printf("%p\n", (void *)&n);   // n의 주소 (예: 0x7ffe...)
```

> 3차시 실습(숫자 맞추기 게임)에서 쓴 `scanf("%d", &guess)`의 `&`가 바로 이것입니다. "값을 저장할 주소"를 넘긴 것. (`scanf`는 입력받은 값을 그 주소에 직접 써넣습니다.)

## 2부: 포인터 선언과 역참조

### 2.1 포인터란?

**주소를 담는 변수**입니다. 타입 뒤에 `*`를 붙여 선언합니다.

```c
int n = 42;
int *p;      // int를 가리키는 포인터
p = &n;      // p에 n의 주소를 저장
```

| 표현 | 의미 |
|------|------|
| `int *p;` | `p`는 int를 가리키는 포인터 |
| `&n` | `n`의 주소 |
| `p = &n;` | `p`가 `n`을 가리킴 |

### 2.2 역참조 연산자 `*`

포인터 앞에 `*`를 붙이면 **그 주소에 있는 값**에 접근합니다. 읽기도 쓰기도 됩니다.

```c
int n = 42;
int *p = &n;

printf("%d\n", *p);   // 42 (p가 가리키는 값을 읽음)
*p = 100;             // p가 가리키는 곳에 100을 씀
printf("%d\n", n);    // 100 (n이 바뀜!)
```

`*p`와 `n`은 **같은 메모리**를 가리킵니다. 하나를 바꾸면 둘 다 바뀐 것처럼 보입니다.

### 2.3 `*`의 두 가지 얼굴

```c
int *p;     // 선언: "p는 포인터다"
*p = 5;     // 사용: "p가 가리키는 곳에 5"
```

선언할 때의 `*`와 사용할 때의 `*`는 문법적으로 다른 역할입니다. 헷갈리지 마세요.

## 3부: 포인터로 원본 바꾸기

### 3.1 4차시의 한계를 넘다

4차시에서 값 전달은 **복사**라서 함수가 원본을 못 바꿨습니다. 주소를 넘기면 함수가 원본에 직접 접근할 수 있습니다.

```c
void try_change(int x)   { x = 100; }       // 복사 — 원본 안 바뀜
void real_change(int *p) { *p = 100; }       // 주소 — 원본 바뀜!

int main(void)
{
    int a = 5;
    try_change(a);
    printf("%d\n", a);    // 5
    real_change(&a);
    printf("%d\n", a);    // 100
    return (0);
}
```

### 3.2 swap — 포인터의 대표 예제

두 변수의 값을 맞바꾸려면 두 주소를 넘겨야 합니다.

```c
void swap(int *a, int *b)
{
    int tmp = *a;   // a가 가리키는 값을 보관
    *a = *b;        // b의 값을 a 자리에
    *b = tmp;       // 보관한 값을 b 자리에
}

int main(void)
{
    int x = 3, y = 7;
    swap(&x, &y);          // 주소를 넘김
    printf("%d %d\n", x, y);   // 7 3
    return (0);
}
```

> 값으로 넘긴 swap은 동작하지 않습니다. 반드시 **주소**(`&x`, `&y`)를 넘기고, 함수는 **포인터**(`int *`)로 받습니다.

## 4부: 포인터 안전과 NULL

### 4.1 초기화 안 한 포인터는 위험

어디를 가리키는지 모르는 포인터를 역참조하면 프로그램이 죽습니다 (segmentation fault).

```c
int *p;       // 쓰레기 주소
*p = 5;       // 위험! 어딘지 모를 곳에 씀 → 크래시
```

### 4.2 NULL 포인터

"아무 곳도 가리키지 않음"을 나타내는 값이 `NULL`입니다. 초기화할 때 안전하게 씁니다.

```c
int *p = NULL;   // 아무것도 안 가리킴

if (p != NULL)   // 쓰기 전에 확인하는 습관
    *p = 5;
```

> libsbs의 `malloc` 계열 함수는 실패 시 `NULL`을 반환합니다. NULL 체크는 메모리 함수 구현(10~11차시)의 필수 습관입니다.

### 4.3 포인터도 타입이 있다

`int *`는 int를, `char *`는 char를 가리킵니다. 타입이 맞아야 역참조 크기가 맞습니다. 7차시 문자열에서 `char *`를 본격적으로 다룹니다.

## 핵심 정리

1. 모든 변수는 메모리에 **주소**를 가진다
2. `&n` = n의 주소, `*p` = p가 가리키는 값
3. 포인터는 **주소를 담는 변수** (`int *p;`)
4. `*p = 값`으로 원본을 직접 수정할 수 있다
5. 함수에 **주소를 넘기면** 원본을 바꿀 수 있다 (swap)
6. 초기화 안 한 포인터 역참조는 크래시 → `NULL`로 초기화하고 확인
