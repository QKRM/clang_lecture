# 5차시 심화 실습 - 포인터 한 걸음 더

> 기본 실습 4과제를 끝낸 학생용. 강의 [advanced.md](advanced.md)와 짝을 이룹니다.

## 심화 실습 목표

- 출력 매개변수로 함수가 여러 값을 돌려주게 만든다.
- 이중 포인터로 값에 접근한다.
- 포인터 타입에 따른 이동 폭을 직접 확인한다.

---

## 심화 1: 출력 매개변수

`divmod.c` 파일을 만들고 한 번의 호출로 몫과 나머지를 모두 구하세요.

요구사항:
- `void divmod(int a, int b, int *quot, int *rem)` 구현
- `void min_max(int a, int b, int *min, int *max)` 구현
- `main`에서 결과 담을 변수의 주소를 넘겨 호출

출력 예시:
```
17 / 5 → 몫=3 나머지=2
min=3 max=8
```

힌트:
```c
void divmod(int a, int b, int *quot, int *rem)
{
    *quot = a / b;
    *rem = a % b;
}
/* 호출: divmod(17, 5, &q, &r); */
```

생각해보기: `return`은 값을 하나만 돌려주는데, 어떻게 두 값을 받았을까?

## 심화 2: 이중 포인터

`double_pointer.c` 파일을 만들고 이중 포인터로 값을 따라가세요.

요구사항:
- `int n = 42;`, `int *p = &n;`, `int **pp = &p;`
- `n`, `*p`, `**pp`가 모두 42인지 출력
- `**pp = 100;`으로 바꾼 뒤 `n` 출력 → 100 확인

힌트:
```c
int **pp = &p;
printf("%d\n", **pp);   // pp → p → n
**pp = 100;             // n까지 거슬러 올라가 수정
```

> `*pp`는 `p`(주소), `**pp`는 `n`(값). 한 단계씩 따라간다.

## 심화 3: const 포인터

`const_ptr.c` 파일을 만들고 읽기 전용 포인터를 실험하세요.

요구사항:
- `void print_value(const int *p)` — 값을 읽어서 출력만
- 함수 안에서 `*p = 100;`을 주석으로 넣어보고, 주석을 풀면 컴파일 에러가 나는지 확인

힌트:
```c
void print_value(const int *p)
{
    printf("%d\n", *p);   // 읽기 OK
    /* *p = 100; */       // 주석 풀면 에러
}
```

생각해보기: `const`가 막아주는 실수는 무엇인가? 왜 읽기 함수에 붙이면 좋은가?

## 심화 4: 포인터 이동 폭 (심화의 심화, 20분)

`ptr_size.c` 파일을 만들고 타입에 따라 `p + 1`의 이동 폭이 다름을 확인하세요.

요구사항:
- `int *`와 `char *`에 대해 `p`와 `p + 1`의 주소를 출력
- 두 주소의 차이를 바이트로 출력 (int=4, char=1 예상)
- `sizeof(int *)`, `sizeof(char *)` 출력 (둘 다 같음 확인)

힌트:
```c
printf("int  차이 = %ld\n",
       (long)((char *)(pi + 1) - (char *)pi));   // 4
printf("char 차이 = %ld\n", (long)((pc + 1) - pc)); // 1
```

> 포인터 자체 크기는 타입과 무관하게 일정(보통 8바이트). 하지만 `+1` 이동 폭은 가리키는 타입 크기.
