# 5차시 실습 - 포인터 기초

## 실습 목표

- `&`와 `*`로 주소를 얻고 값을 역참조한다.
- 포인터로 함수에서 원본 변수를 수정한다.
- `swap` 함수를 포인터로 구현한다.


---

## 과제 1: 주소와 역참조

`pointer_basics.c` 파일을 만들고 포인터의 기본 동작을 확인하세요.

요구사항:
- `int n = 42;` 선언
- `int *p = &n;`으로 포인터에 주소 저장
- `n`의 값, `n`의 주소, `p`의 값, `*p`의 값 출력
- `*p = 100;`으로 바꾼 뒤 `n` 출력 → 바뀜 확인

힌트:
```c
int n = 42;
int *p = &n;
printf("n   값   = %d\n", n);
printf("n   주소 = %p\n", (void *)&n);
printf("*p  값   = %d\n", *p);
*p = 100;
printf("*p로 수정 후 n = %d\n", n);
```

> 주소를 `%p`로 출력할 때 `(void *)`로 캐스팅하면 경고가 사라집니다.

## 과제 2: swap — 포인터로 교환

`swap.c` 파일을 만들고 두 변수의 값을 맞바꾸는 함수를 작성하세요.

요구사항:
- `void swap(int *a, int *b)` 구현
- `main`에서 `x=3, y=7`을 만들고 `swap(&x, &y)` 호출
- 교환 전후 출력

출력 예시:
```
교환 전: x = 3, y = 7
교환 후: x = 7, y = 3
```

힌트:
```c
void swap(int *a, int *b)
{
    int tmp = *a;
    *a = *b;
    *b = tmp;
}
```

> **주의**: 반드시 `&x`, `&y`(주소)를 넘기세요. 값을 넘기면 교환되지 않습니다.

## 과제 3: 포인터로 원본 수정

`modify.c` 파일을 만들고 포인터로 원본을 바꾸는 함수 두 개를 작성하세요.

요구사항:
- `void add_one(int *p)` — 가리키는 값에 1을 더함
- `void set_to_ten(int *p)` — 가리키는 값을 10으로 만듦
- `main`에서 `a=5`로 시작해 각 함수 호출 후 출력

출력 예시:
```
시작: a = 5
add_one 후: a = 6
set_to_ten 후: a = 10
```

힌트:
```c
void add_one(int *p)
{
    *p = *p + 1;
}
```

## 과제 4: 포인터 추적 (심화, 25분)

`pointer_trace.c` 파일을 만들고 하나의 포인터가 여러 변수를 가리키도록 바꿔가며 추적하세요.

요구사항:
- `a=10, b=20` 두 변수
- 포인터 `p`가 `a`를 가리킬 때 `*p`로 `a`를 수정
- `p`가 `b`를 가리키도록 바꾼 뒤 `*p`로 `b`를 수정
- 각 단계에서 `a`, `b` 출력

생각해보기: `p = &a`일 때 `*p`를 바꾸면 왜 `b`는 그대로일까?

```c
int *p = &a;
*p = 11;      // a만 바뀜
p = &b;       // 이제 b를 가리킴
*p = 21;      // b만 바뀜
```
