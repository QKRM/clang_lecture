# 5차시: 포인터 기초

## 학습 목표

1. 메모리와 주소의 개념을 설명할 수 있다
2. `&`(주소)와 `*`(역참조)를 사용할 수 있다
3. 포인터를 선언·초기화할 수 있다
4. 포인터로 원본 값을 수정할 수 있다
5. `swap`을 포인터로 구현할 수 있다

---

## 핵심 개념

### 1. 주소와 `&`

모든 변수는 메모리에 주소를 가진다. `&`로 주소를 얻는다.

```c
int n = 42;
printf("%p\n", (void *)&n);   // n의 주소
```

> 3차시 `scanf("%d", &guess)`의 `&`가 바로 이것.

---

### 2. 포인터 선언과 역참조

포인터 = 주소를 담는 변수. `*`로 가리키는 값에 접근.

```c
int n = 42;
int *p = &n;   // p가 n을 가리킴

printf("%d\n", *p);   // 42 (읽기)
*p = 100;             // 쓰기 → n이 100으로
```

| 표현 | 의미 |
|------|------|
| `int *p;` | p는 포인터 |
| `&n` | n의 주소 |
| `*p` | p가 가리키는 값 |

---

### 3. `*`의 두 얼굴

```c
int *p;     // 선언: "포인터다"
*p = 5;     // 사용: "가리키는 곳에 5"
```

---

### 4. 포인터로 원본 수정

값 전달(복사)의 한계를 주소로 넘는다.

```c
void real_change(int *p) { *p = 100; }

int main(void)
{
    int a = 5;
    real_change(&a);     // 주소를 넘김
    printf("%d\n", a);   // 100 — 바뀜!
}
```

---

### 5. swap — 대표 예제

```c
void swap(int *a, int *b)
{
    int tmp = *a;
    *a = *b;
    *b = tmp;
}
/* 호출: swap(&x, &y); — 반드시 주소 */
```

---

### 6. NULL과 안전

초기화 안 한 포인터 역참조 = 크래시(segfault).

```c
int *p = NULL;        // 안전 초기화
if (p != NULL)        // 쓰기 전 확인
    *p = 5;
```

> `malloc`은 실패 시 NULL 반환. NULL 체크는 10~11차시 메모리 함수의 필수.

## 트러블슈팅

| 증상 | 확인 사항 |
|------|----------|
| `segmentation fault` | 초기화 안 한/NULL 포인터 역참조 |
| swap 후 값이 그대로 | 값을 넘김 → `&x`, `&y`로 주소 전달 |
| `%p` 경고 | `(void *)`로 캐스팅 |
| `*p`가 이상한 값 | `p = &n;`으로 가리키게 했는지 확인 |
| 선언에서 `*` 혼동 | `int *p;`는 선언, `*p = 5`는 사용 |
