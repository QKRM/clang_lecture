Slide 06 / strdup14차시: 문자열 함수 III

sbs_strdup — 동적 복제

while (s[len]) len++;
dup = malloc(len + 1);
if (dup == NULL)
  return (NULL);
while (i < len)
  dup[i] = s[i], i++;
dup[len] = '\0';
return (dup);

malloc(len + 1)

\0 자리를 위해 +1. NULL 검사 필수, 복사 후 \0 종결.

free 책임은 호출자

반환 메모리는 원본과 독립. 다 쓰면 호출자가 free(누수 방지).

실습 ③ — strdup

#include <stdlib.h>

while (s[len]) len++;
dup = malloc(len + 1);
if (dup==NULL)
  return (NULL);
while (i<len)
  dup[i]=s[i], i++;
dup[len]='\0';

3가지 필수

① malloc(len+1)로 \0 자리 ② NULL 검사 ③ \0 종결. free는 호출자 책임.
