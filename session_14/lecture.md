# 14차시 강의 노트 - 문자열 비교와 변환 (strncmp, atoi)

이번 차시는 문자열을 **비교**하고(`strncmp`), 문자열을 **정수로 변환**하는(`atoi`) 함수를 만듭니다. 둘 다 새 메모리를 만들지 않고 입력을 읽어 결과를 계산하는 함수입니다. (문자열 복제 `strdup`은 11차시에서 다뤘습니다.)

## 학습 목표

1. `sbs_strncmp`로 문자열을 n글자까지 비교할 수 있다.
2. `sbs_atoi`로 문자열을 정수로 변환하며 부호·공백을 처리할 수 있다.

---

## 1부: sbs_strncmp

`s1`과 `s2`를 최대 `n`글자 비교. 처음 다른 글자의 차이를 반환, 같으면 0. **`\0`을 만나면 멈춤**(memcmp와 다른 점).

```c
int sbs_strncmp(const char *s1, const char *s2, size_t n)
{
    size_t i = 0;
    while (i < n)
    {
        if (s1[i] != s2[i] || s1[i] == '\0')
            return ((unsigned char)s1[i] - (unsigned char)s2[i]);
        i++;
    }
    return (0);
}
```

핵심 포인트:
- `s1[i] == '\0'`이면 종료(문자열 끝). 한쪽이 짧으면 그 자리에서 결판
- `unsigned char`로 캐스팅해 차이 계산(부호 정확)
- 반환값의 **부호**가 중요

> memcmp(11차시)는 n바이트를 무조건 보지만, strncmp는 `\0`에서 멈춥니다.

## 2부: sbs_atoi

문자열을 정수로 변환합니다. 표준 `atoi`의 동작 순서를 그대로 따릅니다.

### 2.1 처리 순서

1. **선행 공백** 건너뛰기 (스페이스, 탭, 개행 등)
2. **부호** `+`/`-` 한 개 처리
3. **숫자**를 만나는 동안 누적
4. 숫자가 아닌 문자를 만나면 중단

```c
static int is_space(char c)
{
    return (c == ' ' || c == '\t' || c == '\n'
        || c == '\v' || c == '\f' || c == '\r');
}

int sbs_atoi(const char *str)
{
    int  i = 0;
    int  sign = 1;
    long result = 0;

    while (is_space(str[i]))           // 1. 공백
        i++;
    if (str[i] == '+' || str[i] == '-')// 2. 부호
    {
        if (str[i] == '-')
            sign = -1;
        i++;
    }
    while (str[i] >= '0' && str[i] <= '9')  // 3. 숫자 누적
    {
        result = result * 10 + (str[i] - '0');
        i++;
    }
    return ((int)(result * sign));
}
```

### 2.2 엣지 케이스

| 입력 | 결과 | 이유 |
|------|------|------|
| `"42"` | 42 | 기본 |
| `"-42"` | -42 | 부호 |
| `"   123"` | 123 | 선행 공백 |
| `"12ab"` | 12 | 숫자만 |
| `"abc"` | 0 | 숫자 없음 |
| `"+-5"` | 0 | 부호 한 개만 |

> `'5' - '0'` = 5(2차시 ASCII). `result`를 `long`으로 두면 큰 수에서 조금 안전합니다.

---

## 핵심 정리

1. `strncmp`는 n글자 비교, `\0`에서 멈춤, 부호 중요(unsigned char)
2. `atoi`는 공백 → 부호 → 숫자 순으로 처리
3. `'문자' - '0'`로 숫자 문자를 정수로
4. 엣지 케이스가 점수를 가른다(빈 입력, 부호만, 혼합)
