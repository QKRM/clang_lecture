# 14차시 강의 노트 - 문자열 비교와 변환 (strncmp, atoi)

이번 차시는 문자열을 **비교**하고(`strncmp`), 문자열을 **정수로 변환**하는(`atoi`) 함수를 만듭니다. 둘 다 새 메모리를 만들지 않고 입력을 읽어 결과를 계산하는 함수입니다. (문자열 복제 `strdup`은 11차시에서 다뤘습니다.)

## 학습 목표

1. `sbs_strncmp`로 문자열을 n글자까지 비교할 수 있다.
2. `sbs_atoi`로 문자열을 정수로 변환하며 부호·공백을 처리할 수 있다.

---

## 0부: 들어가며 — 비교와 변환은 어디에 쓰이나

### 문자열 "비교"가 필요한 곳

컴퓨터는 문자열을 `==`로 비교 못 합니다(12차시에서 배웠듯 주소 비교라 소용없음). `strncmp`는 접두어(prefix)만 비교할 때 특히 유용합니다.

| 분야 | 예시 |
|------|------|
| 버전 비교 | `"v1.2"` vs `"v1.10"` 앞자리만 비교해 같은 메이저 버전인지 |
| 명령어 파싱 | 사용자가 입력한 문자열이 `"exit"`로 시작하는지(`strncmp(input, "exit", 4)`) |
| 파일 매직 넘버 | 파일 앞 몇 바이트로 포맷 판별(`"PNG"`, `"GIF8"` 등) |

### 문자열 → 정수 "변환"이 필요한 곳

프로그램 입력은 대부분 **문자열**로 들어옵니다(커맨드라인 인자, 사용자 입력, 설정 파일). 하지만 계산하려면 **정수**가 필요합니다. `argv[1]`은 항상 `char *`이지 `int`가 아닙니다.

```c
int main(int argc, char *argv[])
{
    int n = sbs_atoi(argv[1]);   // "42" (문자열) → 42 (정수)
}
```

| 분야 | 예시 |
|------|------|
| 커맨드라인 인자 | `./calc 3 + 5` → `argv[1]`, `argv[3]`을 정수로 변환 |
| 설정 파일 | `"port=8080"`에서 `8080` 부분을 정수로 |
| 사용자 입력 | 나이·개수 등 숫자를 입력받아 계산 |

## 1부: sbs_strncmp

`s1`과 `s2`를 최대 `n`글자 비교. 처음 다른 글자의 차이를 반환, 같으면 0. **`\0`을 만나면 멈춤**(memcmp와 다른 점).

동작 순서 (코드는 실습에서 직접 작성):

1. `i`를 0부터 `n` 미만인 동안 반복
2. `s1[i]`와 `s2[i]`가 **다르거나**, `s1[i]`가 `\0`이면 → 두 글자의 차이를 반환 (여기서 멈춤)
3. `n`글자를 다 봤는데 전부 같았으면 `0` 반환

```
strncmp("apple", "apply", 5)
 a  p  p  l  e
 a  p  p  l  y
 =  =  =  =  ≠   → 'e'(101) - 'y'(121) = -20 (음수 = s1이 앞선다)
```

한쪽이 짧으면? `"app"` vs `"apple"` → `i=3`에서 `s1[3]`이 `\0` → `'\0'(0) - 'l'(108)` = 음수. **짧은 쪽이 사전순으로 앞**이라는 결과가 자연스럽게 나옵니다.

핵심 포인트:
- `s1[i] == '\0'`이면 종료(문자열 끝). 한쪽이 짧으면 그 자리에서 결판
- `unsigned char`로 캐스팅해 차이 계산(부호 정확)
- 반환값의 **부호**가 중요

> memcmp(11차시)는 n바이트를 무조건 보지만, strncmp는 `\0`에서 멈춥니다.

## 2부: sbs_atoi

문자열을 정수로 변환합니다. 표준 `atoi`의 동작 순서를 그대로 따릅니다.

### 2.1 처리 순서

1. **선행 공백** 건너뛰기 (스페이스, 탭, 개행 등 6종: ` ` `\t` `\n` `\v` `\f` `\r`)
2. **부호** `+`/`-` 한 개 처리 (`-`면 부호 변수를 -1로)
3. **숫자**(`'0'`~`'9'`)를 만나는 동안 누적: `결과 = 결과 × 10 + (글자 - '0')`
4. 숫자가 아닌 문자를 만나면 중단, `결과 × 부호` 반환

(코드는 실습에서 직접 작성합니다. 공백 판별은 `is_space` 같은 보조 함수로 빼면 깔끔합니다.)

### 숫자 누적의 원리

`"123"`을 왼쪽부터 읽으며 자릿수를 올립니다:

```
글자 '1':  result = 0 × 10 + 1 = 1
글자 '2':  result = 1 × 10 + 2 = 12
글자 '3':  result = 12 × 10 + 3 = 123
```

`'1' - '0'` = 1처럼 **문자에서 숫자로**는 ASCII 뺄셈(2차시)으로 얻습니다.

### 2.2 엣지 케이스

| 입력 | 결과 | 이유 |
|------|------|------|
| `"42"` | 42 | 기본 |
| `"-42"` | -42 | 부호 |
| `"   123"` | 123 | 선행 공백 |
| `"12ab"` | 12 | 숫자만 |
| `"abc"` | 0 | 숫자 없음 |
| `"+-5"` | 0 | 부호 한 개만 |

> `'5' - '0'` = 5(2차시 ASCII). `result`를 `long`으로 두면 큰 수에서 조금 안전합니다.

## 2.3 손으로 추적하기 — atoi("  -42x") 상태 진행표

코드를 짜기 전에 `i`, `sign`, `result`가 한 글자씩 어떻게 바뀌는지 표로 따라가 보세요.

| i | str[i] | 단계 | sign | result | 비고 |
|---|--------|------|------|--------|------|
| 0 | ' ' | 1.공백 건너뛰기 | 1 | 0 | i++ |
| 1 | ' ' | 1.공백 건너뛰기 | 1 | 0 | i++ |
| 2 | '-' | 2.부호 처리 | -1 | 0 | i++ |
| 3 | '4' | 3.숫자 누적 | -1 | 4 | result=0*10+4 |
| 4 | '2' | 3.숫자 누적 | -1 | 42 | result=4*10+2 |
| 5 | 'x' | 4.숫자 아님 → 중단 | -1 | 42 | 루프 탈출 |

최종 반환값: `result * sign` = `42 * -1` = **-42**.

직접 채워볼 것: `atoi("+007")`과 `atoi("abc")` — 각각 몇 단계에서 루프가 끝나는지 표로 그려보세요.

## 핵심 정리

1. `strncmp`는 n글자 비교, `\0`에서 멈춤, 부호 중요(unsigned char)
2. `atoi`는 공백 → 부호 → 숫자 순으로 처리
3. `'문자' - '0'`로 숫자 문자를 정수로
4. 엣지 케이스가 점수를 가른다(빈 입력, 부호만, 혼합)
