GitHub Codespaces란?

한 줄 정의

브라우저에서 바로 실행되는 클라우드 개발 환경

내 PC에 아무것도 설치하지 않아도 VS Code와 동일한 환경에서 코딩 가능

우리 강의에서 쓰는 이유

  • ✓gcc 컴파일러가 기본 설치된 Linux 환경 즉시 사용
  • ✓Windows/Mac 관계없이 동일한 환경 보장
  • ✓설치 문제로 수업 시간 낭비 없음

Codespaces 주요 특징

무료

개인 계정 기준 월 60시간 무료 (강의 분량 충분)

저장

코드는 자동으로 GitHub 리포지토리에 저장됨

접속

PC, 태블릿, 어느 기기에서든 동일한 환경 접속

주의

30분 이상 아무 활동이 없으면 자동 정지됩니다. 코드는 유지되며, 재접속하면 즉시 다시 시작됩니다.

Slide 07 / What is C 1차시: Codespaces 세팅 + C언어 첫걸음

C언어란?

1972

역사

Dennis Ritchie가 Bell Labs에서 개발. UNIX 운영체제를 만들기 위해 탄생했습니다.

특징

  • →하드웨어에 가까운 저수준 제어
  • →매우 빠른 실행 속도
  • →포인터로 메모리 직접 접근
  • →컴파일 언어 (실행 전 빌드 필요)

사용처

  • ✓운영체제 (Linux, Windows 커널)
  • ✓임베디드 시스템, 펌웨어
  • ✓데이터베이스 (SQLite, PostgreSQL)
  • ✓다른 언어의 인터프리터(Python 등)

이 강의에서 C언어를 배우는 이유

포인터와 메모리를 이해하면 모든 프로그래밍 언어의 동작 원리가 보입니다. libsbs를 직접 구현하면서 "표준 라이브러리가 어떻게 만들어졌는지" 처음부터 파악합니다.

Slide 10 / Code Analysis 1차시: Codespaces 세팅 + C언어 첫걸음

코드 한 줄씩 분석

#include <stdio.h>

전처리기 지시문 — 헤더 파일 포함

stdio.h(Standard I/O)는 printf, scanf 등 입출력 함수가 정의된 헤더. 이것 없이 printf를 쓰면 컴파일 에러가 납니다.

int main(void)

프로그램의 진입점(Entry Point)

int: 정수를 반환하는 함수 / main: C 프로그램은 항상 main에서 시작 / void: 인자 없음

printf("...\n");

화면에 출력하는 함수

stdio.h에 정의된 함수. \n은 줄바꿈(개행). 문장 끝에 반드시 ; 세미콜론이 붙어야 합니다.

return (0);

프로그램 종료 신호

0은 정상 종료를 의미. 운영체제가 이 값을 받아 프로그램 성공/실패를 판단. 1 이상이면 에러로 처리.

Slide 11 / Compile 1차시: Codespaces 세팅 + C언어 첫걸음

컴파일과 실행 — 소스 코드 → 실행 파일

컴파일 과정

hello.c → 전처리 → .i → 컴파일 → .s → 어셈블 → .o → 링킹 → hello

gcc는 이 4단계를 한 번에 처리합니다

기본 컴파일 명령어 
$ gcc hello.c -o hello
gccGNU C Compiler 프로그램
hello.c컴파일할 소스 파일
-o hello출력 파일 이름을 hello로 지정
실행 
$ ./hello
Hello, World!

./는 현재 디렉토리에서 실행. Linux에서는 실행 파일을 경로 없이 실행하면 시스템 PATH에서만 찾으므로 ./를 붙입니다.

컴파일 에러가 나면?

  • →세미콜론 ; 누락 여부 확인
  • →#include <stdio.h> 첫 줄에 있는지 확인
  • →파일명 오타 확인 (ls로 파일 목록 체크)

Slide 12 / Compiler Flags 1차시: Codespaces 세팅 + C언어 첫걸음

컴파일 옵션 — 이 강의에서 항상 사용하는 설정

표준 컴파일 명령어 
$ gcc -Wall -Wextra -Werror hello.c -o hello
옵션 의미
-Wall대부분의 경고(warning) 표시
-Wextra추가적인 경고 표시
-Werror경고를 에러로 처리 (경고 → 컴파일 실패)

왜 이렇게 까다롭게 쓰나요?

  • ① libsbs 과정 libsbs 프로젝트 요구사항입니다. 경고가 하나라도 있으면 평가에서 탈락합니다.
  • ② 경고는 잠재적 버그 신호입니다. 무시하면 나중에 찾기 어려운 버그가 됩니다.
  • ③ 처음부터 깨끗한 코드 작성 습관을 기릅니다.

경고 예시

hello.c:5:5: warning: unused variable 'x'
  [-Wunused-variable]
    int x = 1;
        ^

-Werror이면 이것만으로 컴파일 실패

Slide 13 / printf 1차시: Codespaces 세팅 + C언어 첫걸음

printf — 서식 지정자와 이스케이프 문자

코드 예시 
#include <stdio.h>

int main(void)
{
    int   age    = 25;
    float height = 175.5;
    char  ch     = 'K';

    printf("나이: %d\n", age);
    printf("키: %.1f\n", height);
    printf("문자: %c\n", ch);
    printf("주소: %p\n", &age);
    return (0);
}
서식 지정자
%d정수 (int)
%f실수 (float, double)
%c문자 (char)
%s문자열 (char 배열)
%p포인터 주소 (16진수)
이스케이프 문자
\n줄바꿈 (개행)
\t탭 (들여쓰기)
\\백슬래시 자체
\0null 문자 (문자열 끝) ← 매우 중요!

man page 구조
