Slide 03 / What is a Struct 8차시: 구조체와 typedef

구조체 — 데이터를 하나로 묶기

여러 값을 한 묶음으로

학생 = 이름 + 나이 + 점수

관련 데이터를 한 덩어리로 다루면 코드가 명확해진다.

설계도 → 변수

struct 정의는 설계도. 변수를 만들어야 메모리를 차지한다.

struct student {
    char name[20];
    int  age;
    int  score;
};  // ← 세미콜론 필수!

struct student s1;
struct student s2 =
    {"Kim", 20, 95};

Slide 06 / Pointer -> 8차시: 구조체와 typedef

구조체 포인터 — -> 연산자

t_student s = {"Kim", 20, 95};
t_student *p = &s;

printf("%d", (*p).age);
// 방법1: 역참조 후 점
printf("%d", p->age);
// 방법2: 화살표 (간결)

p->age = (*p).age. 거의 항상 ->를 쓴다.

대상 연산자
구조체 변수s.age
구조체 포인터p->age

왜 포인터?

큰 구조체를 함수에 복사하면 비싸다. 포인터(주소)를 넘기면 복사 없이 원본 접근 (5~6차시).

Slide 07 / Struct Array 8차시: 구조체와 typedef

구조체 배열 — 여러 개를 한꺼번에

t_student class[3] = {
    {"Kim",  20, 95},
    {"Lee",  21, 88},
    {"Park", 22, 77}

for (int i = 0; i < 3; i++)
    printf("%s %d\n",

왜 좋은가

학생 100명을 name[100], age[100], score[100] 세 배열 대신 class[100] 하나로.

접근은 점

class[i]는 구조체 변수 → .로 접근. class[i].name

Slide 08 / Passing Structs 8차시: 구조체와 typedef

구조체를 함수에 — 값 vs 포인터

값 전달 (복사, 읽기) 
void print_student(t_student s)
{
    printf("%s\n", s.name);
}
// 원본 못 바꿈
포인터 전달 (원본 수정) 
void update_score(t_student *p,
                  int sc)
{
    p->score = sc;  // 원본 수정
}

읽기만 하면 값(또는 const 포인터), 바꾸려면 포인터. 5~6차시 원리가 구조체에도 그대로 적용된다.

심화 ⑦⑧ — 최고점 학생 & 거리

⑦ top_student.c 
t_student *find_top(
    t_student *arr, int n)
{
  t_student *top = &arr[0];
  for (i=1; i<n; i++)
    if (arr[i].score > top->score)
      top = &arr[i];
  return (top);
}
⑧ distance.c 
int dist_squared(
    t_point a, t_point b)
{
  int dx = b.x - a.x;
  int dy = b.y - a.y;
  return (dx*dx + dy*dy);
}
// (0,0)~(3,4) → 25

변수 멤버는 `.`, 포인터는 `->`

p->age == (*p).age

3

typedef로 별칭 (`t_student`)

struct 생략 가능

4

문자열 멤버는 strcpy로 채운다

배열은 대입 불가

5

수정하려면 포인터로 전달

읽기는 값, 변경은 포인터
