Slide 05 / memset10차시: 메모리 함수 I

sbs_memset — 값으로 채우기

void *sbs_memset(void *b,
              int c, size_t len)
{
  unsigned char *p = b;
  size_t i = 0;
  while (i < len)
  {
    p[i] = (unsigned char)c;
    i++;
  }
  return (b);
}

동작

b부터 len바이트를 c로 채우고, 첫 인자 b를 그대로 반환한다.

Slide 07 / memcpy10차시: 메모리 함수 I

sbs_memcpy — 메모리 복사

void *sbs_memcpy(void *dst,
       const void *src, size_t n)
{
  unsigned char *d = dst;
  const unsigned char *s = src;
  size_t i = 0;
  while (i < n)
  { d[i] = s[i]; i++; }
  return (dst);
}

겹침 미보장

dst와 src가 겹치면 결과가 보장되지 않는다. 겹치는 복사는 11차시 memmove.
