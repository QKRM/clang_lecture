왜 나누나?

  • →여러 .c가 헤더 하나만 include

4차시에선 프로토타입과 본문이 한 파일이었다. 함수가 많아지면 선언은 .h, 정의는 .c로 나눈다.

Slide 05 / Include Guard 9차시: 헤더 파일 + 문자 분류 함수

인클루드 가드 — 중복 포함 방지

#ifndef LIBSBS_H
# define LIBSBS_H

int sbs_isalpha(int c);
int sbs_isdigit(int c);
/* ... 나머지 프로토타입 ... */

#endif

가드가 없으면?

같은 헤더가 두 번 include되면 선언이 중복되어 redefinition 에러. 큰 프로젝트에서 흔히 발생.

동작 원리

처음엔 LIBSBS_H가 없어 정의 → 내용 포함. 두 번째부터는 이미 정의되어 #endif까지 건너뜀.

매크로 이름은 보통 파일명 대문자 (LIBSBS_H)

Slide 07 / is* Functions 9차시: 헤더 파일 + 문자 분류 함수

분류 함수 — 참이면 0이 아닌 값

int sbs_isalpha(int c)
{
  return ((c>='a'&&c<='z')
       || (c>='A'&&c<='Z'));
}

int sbs_isalnum(int c)
{
  return (sbs_isalpha(c)
       || sbs_isdigit(c));
}
isdigit'0'-'9'
isascii0~127
isprint32~126

함수 재사용

isalnum은 이미 만든 isalpha, isdigit를 조합. 작은 함수를 엮는 감각이 라이브러리의 핵심.

Slide 08 / Conversion 9차시: 헤더 파일 + 문자 분류 함수

변환 함수 — 대상 아니면 그대로

int sbs_toupper(int c)
{
  if (c >= 'a' && c <= 'z')
    return (c - 32);
  return (c);  // 그대로!
}

int sbs_tolower(int c)
{
  if (c >= 'A' && c <= 'Z')
    return (c + 32);
  return (c);
}

자주 하는 실수

변환 대상이 아닐 때 return (c);를 빠뜨림.

숫자·기호·공백도 그대로 반환해야 표준 toupper와 일치합니다. 빠뜨리면 0이 반환되어 대량 오답.
