GitHub Codespaces 활용

Codespaces는 브라우저에서 바로 열리는 클라우드 개발 환경입니다. 설치 없이 VS Code + gcc가 준비됩니다.

생성 순서

  1. github.com 로그인
  2. + → New repository → 이름 libsbs → Add a README 체크 → Create
  3. 리포지토리 → <> Code → Codespaces 탭 → Create codespace on main
  4. 1~2분 대기 → 브라우저에 VS Code 환경이 열림
주의 README 체크를 빠뜨리면 Codespace 생성이 안 됩니다.

환경 확인

$ gcc --version
gcc (Ubuntu 11.4.0) 11.4.0

gcc가 보이면 준비 완료. 안 보이면 로딩이 덜 된 것 — 잠시 후 다시.

컴파일과 실행

소스 코드(.c)를 gcc로 컴파일해 실행 파일을 만들고 돌립니다. gcc 대신 cc를 써도 됩니다(보통 같은 컴파일러를 가리킴).

# 컴파일 (경고를 엄격하게)
$ gcc -Wall -Wextra -Werror hello.c -o hello

# 실행 (./ 를 앞에 붙인다)
$ ./hello
Hello, World!

컴파일 4단계

한 줄 명령처럼 보이지만 내부에서 4단계를 거칩니다.

소스(.c)
  │ ① 전처리 (preprocess)  #include·#define 처리
  ▼
  │ ② 컴파일 (compile)     C → 어셈블리(.s)
  ▼
  │ ③ 어셈블 (assemble)    어셈블리 → 기계어(.o)
  ▼
  │ ④ 링크 (link)          .o + 라이브러리 → 실행 파일
  ▼
실행 파일 (a.out / hello)

필수 경고 옵션

옵션의미
-Wall대부분의 경고 표시
-Wextra추가 경고 표시 (미사용 매개변수 등)
-Werror경고를 에러로 처리 → 경고 있으면 컴파일 실패
-o 이름실행 파일 이름 지정 (없으면 a.out)
libsbs 규칙 항상 -Wall -Wextra -Werror로 컴파일. 경고 0개가 목표입니다.

단계별·디버깅 옵션

옵션역할언제 쓰나
-c링크 없이 .o만 생성여러 파일 분리 컴파일·라이브러리
-E전처리 결과만 출력매크로·include 확인
-S어셈블리(.s) 생성저수준 확인(심화)
-g디버그 정보 포함gdb·valgrind 쓸 때
-O0 ~ -O2최적화 수준 (0=없음)디버그는 -O0, 배포는 -O2
-std=c99C 표준 버전 지정표준 호환성 맞출 때
-I.헤더 검색 경로 추가(현재 폴더)"libsbs.h" 못 찾을 때
-L. -lsbs라이브러리 경로·링크libsbs.a 링크 (15차시)
-fsanitize=address메모리 오류 런타임 검출잘못된 접근·누수 추적(심화)

여러 파일 분리 컴파일

# 각각 .o로 컴파일
$ gcc -Wall -Wextra -Werror -c main.c   -o main.o
$ gcc -Wall -Wextra -Werror -c utils.c  -o utils.o

# .o들을 묶어 실행 파일로 (링크)
$ gcc main.o utils.o -o program
$ ./program

파일이 많아지면 이 과정을 Makefile로 자동화합니다 (15차시).

디버깅 도구와 함께

# 디버그 정보 포함 컴파일 후 메모리 누수 검사
$ gcc -Wall -Wextra -Werror -g main.c -o prog
$ valgrind --leak-check=full ./prog

# 주소 새니타이저 (잘못된 메모리 접근 즉시 검출)
$ gcc -g -fsanitize=address main.c -o prog
$ ./prog
자주 쓰는 조합 평소엔 gcc -Wall -Wextra -Werror, 메모리 버그 추적엔 -g + valgrind 또는 -fsanitize=address.
C · 1차시

Hello World와 소스 구조

#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return (0);
}
  • #include <stdio.h> — 전처리기 지시문. printf 선언을 가져옴
  • int main(void) — 프로그램의 진입점. 실행은 여기서 시작
  • { } — 함수 본문을 감싸는 블록
  • printf("...\n") — 화면 출력, \n은 줄바꿈
  • return (0); — 0 = 정상 종료. OS가 이 값으로 성공/실패 판단
  • 모든 문장은 세미콜론 ;으로 끝남

C · 3차시

조건문과 반복문

조건문 if / else if / else

if (score >= 90)
    printf("A\n");
else if (score >= 80)
    printf("B\n");        // 위에서부터 처음 참인 가지만 실행
else
    printf("F\n");
중괄호 주의 {}를 생략하면 바로 다음 한 문장만 조건에 묶입니다. 항상 {}를 쓰는 습관이 버그를 막습니다.

switch (fall-through 주의)

switch (day)
{
    case 1:
        printf("월\n");
        break;            // 없으면 다음 case로 흘러내림!
    case 2:
        printf("화\n");
        break;
    default:
        printf("기타\n");
}

반복문 3종

for (int i = 0; i < 5; i++)   // 횟수 정해짐
    printf("%d ", i);          // 0 1 2 3 4

int i = 0;
while (i < 5)                 // 조건 기반
{
    printf("%d ", i);
    i++;                      // 종료 조건 변경 (무한루프 방지)
}

do {
    printf("최소 1회\n");      // 먼저 실행 후 조건 검사
} while (0);
상황추천
반복 횟수가 정해짐for
조건 기반 (입력/탐색)while
최소 1회 보장do-while

흐름 제어 + 중첩

for (int i = 0; i < 10; i++)
{
    if (i == 5)
        break;        // 반복 전체 종료
    if (i % 2 == 0)
        continue;     // 현재 회차만 건너뜀
    printf("%d ", i); // 1 3
}

// 중첩 반복문 — 구구단
for (int dan = 2; dan <= 9; dan++)
    for (int n = 1; n <= 9; n++)
        printf("%d x %d = %d\n", dan, n, dan * n);
  • C에서 0은 거짓, 0이 아니면 참 (음수도 참)
  • switch는 각 case 끝에 break 필수
  • break 반복 종료, continue 현재 회차만 건너뜀
  • FizzBuzz: 15의 배수를 가장 먼저 검사 (순서 중요)
C · 4차시

함수와 재귀

선언 · 정의 · 호출

int add(int a, int b);   // 1. 선언(프로토타입) — main 위

int main(void)
{
    int result = add(3, 5);      // 3. 호출
    printf("%d\n", result);      // 8
    return (0);
}

int add(int a, int b)    // 2. 정의 (본문)
{
    return (a + b);
}

C는 위에서 아래로 읽습니다. main 아래 정의된 함수를 호출하려면 위에 프로토타입이 필요합니다.

값에 의한 전달 (pass by value)

void try_change(int x)
{
    x = 100;          // 복사본만 변경
}

int main(void)
{
    int a = 5;
    try_change(a);
    printf("%d\n", a);   // 5  ← 원본 안 바뀜!
}

원본을 바꾸려면 주소(포인터)를 넘겨야 합니다 → 5차시.

재귀 (recursion)

int factorial(int n)
{
    if (n <= 1)              // 종료 조건 (base case) — 필수!
        return (1);
    return (n * factorial(n - 1));   // 재귀 호출
}

// factorial(4) = 4*3*2*1 = 24
  • 함수 = 반환타입 + 이름 + 매개변수 + 본문
  • 인자는 값으로 복사되어 전달 — 원본은 안 바뀜
  • 함수 호출마다 스택 프레임이 쌓이고 return 시 제거
  • 재귀는 종료 조건 + 재귀 호출 두 가지 필수
  • 종료 조건 없으면 스택 오버플로로 크래시
  • void = 반환값 없음 / 매개변수 없음
C · 5차시

포인터 기초

주소와 역참조

int n = 42;
int *p = &n;        // p는 n의 주소를 담음

printf("%d\n", n);          // 42  (값)
printf("%p\n", (void *)&n); // 0x... (주소)
printf("%d\n", *p);         // 42  (*p = 가리키는 값)

*p = 100;           // p가 가리키는 곳에 100
printf("%d\n", n);  // 100  ← n이 바뀜! (*p와 n은 같은 메모리)
표현의미결과
n변수 n값 (42)
&nn의 주소주소 (0x...)
p포인터 p주소 (0x...)
*pp가 가리키는 값값 (42)

swap — 포인터로 원본 교환

void swap(int *a, int *b)
{
    int tmp = *a;   // a가 가리키는 값 보관
    *a = *b;
    *b = tmp;
}

int x = 3, y = 7;
swap(&x, &y);       // 반드시 주소(&)를 넘김
// x=7, y=3

NULL과 안전

int *p;       // 초기화 안 함 → 쓰레기 주소
// *p = 5;    // 위험! 크래시 (segmentation fault)

int *q = NULL;   // 안전하게 초기화
if (q != NULL)   // 쓰기 전 확인
    *q = 5;
  • &n = 값→주소, *p = 주소→값 (반대 방향)
  • 선언의 *(포인터다)와 사용의 *(가리키는 값)는 다른 역할
  • 함수에 주소를 넘기면 원본을 바꿀 수 있다 (swap)
  • 초기화 안 한 포인터 역참조 = 크래시 → NULL로 초기화 후 확인
  • %p 출력엔 (void *) 캐스팅
C · 6차시

배열과 포인터

배열의 메모리 배치

int arr[5] = {10, 20, 30, 40, 50};

// 주소        값
// 0x1000     10   arr[0]
// 0x1004     20   arr[1]   ← int 4바이트씩 증가
// 0x1008     30   arr[2]
// ...

arr == &arr[0]      // 배열 이름 = 첫 원소 주소
int *p = arr;       // & 안 붙임!

포인터 산술

int *p = arr;
*(p + 0)   // arr[0]
*(p + 2)   // arr[2]  ← 포인터 산술 = 인덱스

// 포인터를 직접 이동하며 순회
while (p < arr + 5)
{
    printf("%d ", *p);
    p++;            // 다음 원소 (타입 크기만큼 이동)
}

p + 1은 1바이트가 아니라 타입 크기만큼(int면 4바이트) 이동합니다.

배열을 함수에 전달 (버블 정렬)

void bubble_sort(int *arr, int size)   // 주소가 넘어감 → 원본 변경
{
    for (int i = 0; i < size - 1; i++)
        for (int j = 0; j < size - 1 - i; j++)
            if (arr[j] > arr[j + 1])
            {
                int tmp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = tmp;
            }
}
  • 배열은 메모리에 연속 배치 (int면 4바이트씩)
  • 배열 이름은 첫 원소의 주소 (arr == &arr[0]) — & 안 붙임
  • arr[i]는 사실 *(arr + i)
  • 함수에 배열을 넘기면 주소가 전달되어 원본이 바뀜
  • 함수는 크기를 모르므로 size를 항상 같이 넘긴다
  • 인덱스는 0 ~ size-1. 범위 초과 접근은 위험
C · 7차시

문자열과 포인터

문자열의 구조

char s[6] = "hello";
// 인덱스  0   1   2   3   4   5
// 값     'h' 'e' 'l' 'l' 'o' '\0'
//                             ↑ 끝 표시 (6바이트)

\0이 없으면 문자열이 어디서 끝나는지 알 수 없어 출력·길이 계산이 폭주합니다.

배열 vs 포인터

char  arr[] = "hello";   // 복사본 — 수정 가능
arr[0] = 'H';            // OK → "Hello"

char *ptr = "hello";     // 리터럴 — 읽기 전용
// ptr[0] = 'H';         // 위험! 크래시

포인터로 순회 (길이 세기)

int len = 0;
while (s[len])          // s[len]이 '\0'(0)이면 종료
    len++;

// 또는 포인터로
char *p = s;
while (*p)
{
    printf("%c", *p);
    p++;
}

문자 다루기 (ASCII)

// 대문자로 ('a'~'z'만 -32)
if (c >= 'a' && c <= 'z')
    c = c - 32;

// 뒤집기 (양끝 → 가운데 swap)
int left = 0, right = len - 1;
while (left < right)
{
    char tmp = s[left];
    s[left] = s[right];
    s[right] = tmp;
    left++; right--;
}
  • 문자열 = char 배열 + 끝의 \0 (null terminator)
  • "hello"는 글자 5 + \0 1 = 6바이트
  • char arr[]는 수정 가능, char *p = "..."는 읽기 전용(수정 시 크래시)
  • while (*p)로 \0까지 순회 (길이를 몰라도 됨)
  • 문자는 ASCII 정수 — 대소문자는 ±32
  • 복사할 땐 마지막에 \0을 꼭 붙인다
C · 8차시

구조체와 typedef

구조체 선언과 typedef

typedef struct s_student
{
    char name[20];
    int  age;
    int  score;
}   t_student;          // 별칭 → struct 생략 가능

t_student s = {"Kim", 20, 95};   // 멤버 순서대로 초기화

구조체 정의 끝에 세미콜론 }; 필수. 빠뜨리면 컴파일 에러.

멤버 접근 — . 과 ->

t_student s = {"Kim", 20, 95};
printf("%d\n", s.age);        // 변수는 점(.)

t_student *p = &s;
printf("%d\n", p->age);       // 포인터는 화살표(->)
p->age++;                     // 원본 수정 (p->age == (*p).age)

문자열 멤버 + 구조체 배열

#include <string.h>

strcpy(s.name, "Kim");   // 배열은 대입 불가 → 복사

t_student class[3] = {
    {"Kim", 20, 95},
    {"Lee", 21, 88},
    {"Park", 22, 77}
};
for (int i = 0; i < 3; i++)
    printf("%s %d\n", class[i].name, class[i].score);

함수에 전달

void print_student(t_student s);          // 값 (복사, 읽기)
void set_score(t_student *p, int sc)      // 포인터 (원본 수정)
{
    p->score = sc;
}
  • 구조체 = 서로 다른 데이터를 하나로 묶기
  • 정의 끝에 }; 세미콜론 필수
  • 변수 멤버는 ., 포인터 멤버는 -> (p->age == (*p).age)
  • typedef로 별칭 → struct 생략
  • 문자열 멤버는 strcpy로 채움 (대입 불가)
  • 읽기만 하면 값 전달, 수정하려면 포인터 전달
